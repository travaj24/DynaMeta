## Part 2: the in-Newton density gradient for equilibrium regions

### Formulation (`carriers/physics_equilibrium_dg.py`, new)

Convention: Lambda in volts acts on the electrons' band edge, E_c,eff = E_c - q Lambda, with

    Lambda = b lap(sqrt n) / sqrt n,    b = gamma hbar^2 / (6 m q)

i.e. the quantum potential energy added to E_c is -q Lambda = -(gamma hbar^2/(2 m r)) lap(sqrt n)/sqrt n with r = 3
(the library's existing convention, `physics_density_gradient.dg_b_coefficient`). Near an insulating wall
lap(sqrt n)/sqrt n < 0, so Lambda < 0 and electrons are pushed off the wall. In equilibrium the electrochemical
potential is flat, so the Fermi-Dirac closure becomes

    n = N_c F_1/2(eta + Lambda/V_t),    eta = (psi - [EF_ref] - Phi_c0)/V_t        (Aymerich-Humet F_1/2)

There is no continuity equation; the DG adds two nodal unknowns u = sqrt(n) (QSqrtN) and Lambda (QLambda):

    Poisson     div(eps grad psi) = q (n(psi, Lambda) - N_D) - (fixed / trap terms)     (unchanged row)
    u-row       u^2 - n(psi, Lambda) = 0                                                (the closure tie)
    Lambda-row  b lap(u) - Lambda u = 0                                                 (shared DG kernel)

The Lambda-row is `physics_density_gradient._install_dg_variables` (the drift-diffusion / bipolar DG kernel; no
second implementation) with the tie replaced. Jacobian: analytic. The `Electrons` node model is redefined on
eta + Lambda/V_t with `Electrons:Potential` and `Electrons:QLambda` from DEVSIM's unsimplified `diff()` (exact, < 1 ms;
the 150-300 s `simplify()` of the Aymerich-Humet derivative is avoided), Poisson gains `PotentialNodeCharge:QLambda`,
and DEVSIM's `diff()` carries those names into the tie's derivatives. Signs are pinned by the frozen-potential oracle
below (a wrong sign accumulates at the wall).

Boundary conditions. Insulating wall (every node of the region on an interface with a dielectric region): u = u_floor
(1e-6 sqrt(n_bg), a positive floor because u's update is 'positive'); the tie still sets Lambda there (~V_t
ln(u_floor^2/n), the finite stand-in for the log divergence); the Lambda-row is replaced. DEVSIM cannot put a contact
on an interface edge (MEASURED: a contact on the film/oxide line deletes the interface), so the replacement is a node
mask: at a wall node the node term is K (u - u_floor) instead of Lambda u, K = 1e10 b_full (A_node/NodeVolume)^2,
which outweighs the wall node's edge fluxes by 2e10 (b_full/b); the Dirichlet then holds to 1e-10 of the neighbouring
u. An ohmic contact on the region (the 3-D body contact, a pinned edge electrode) is a reservoir: Lambda = 0 and
u^2 = n (contact rows). Elsewhere (lateral cell edges) the natural condition, zero normal gradient of u.
Interface traps keep the classical eta (a localized state's occupancy depends on E_F - E_c, not on the carriers'
quantum potential).

Newton robustness (all opt-in paths only): Lambda's updates are log-damped like the potential's; the closure argument
is floored at eta = -600 (exp overflow in a Newton transient is a DEVSIM FATAL, MEASURED on depleted 3 nm films; a
converged state never comes near); the seed places every wall node at the floor even at b = 0 (from Lambda = 0 the
tie's Newton walks Lambda down by ~V_t per iteration); bias and b ramps use adaptive step halving
(`adaptive_continuation`): a 3 nm 1e26 m^-3 film driven to full depletion fails in 0.25 V steps and converges in
0.02 V steps (MEASURED). gamma = 0 installs nothing.

Not supported (refused with a message): a Kane band (the quantization mass and the calibration are those of a
parabolic band; the Schrodinger-Poisson reference's in-plane Kane model is a different band, P13 note), a region with
an interface to another semiconductor (u and Lambda would need interface conditions), non-equilibrium physics.

### Calibration against the dual-gate Schrodinger-Poisson solver

Reference: `DualGateSchrodingerPoisson` (P12: sub-band eigenstates, hard walls, parabolic band, 300 K, Gauss's law at
both faces), h = 0.0125 nm. DG: the 2-D builder on its DEFAULT mesh, one-cell-wide laterally uniform device
(`validation/_eqdg_fixture.py`). Metrics, relative to S = max(n_bg t, the SP carrier sheet): sheet-excess error (the
electrostatics) and the profile L1 error int |n_DG - n_SP| dz (Friedel oscillations included).

Wall condition. The hard wall (u = 0 at the oxide face) with gamma alone fits the sheet to <= 1 % everywhere in range,
so no second wall parameter (penetration length, Robin wall) is identified by these data: the remaining profile error
is SP's Friedel oscillation, which no local wall condition reproduces. No trend of gamma* with bias, thickness,
density or mass beyond the 10-90 % band was found.

Default rule: **gamma = 1.8 with the hard wall** (`EQUILIBRIUM_DG_GAMMA`). A priori check: the T -> 0 Fermi-Dirac DG
dark space at a hard wall integrates in closed form, deficit = sqrt(gamma/3) I_TF/k_F, I_TF = int_0^1 (1 - w^2)/
sqrt(3 w^(10/3)/5 - w^2 + 2/5) dw = 1.64378; matching the free-gas Friedel deficit 3 pi/(8 k_F) gives gamma_TF =
1.541. The fit is 17 % above it; the Boltzmann wall value GAMMA_WALL is 1.67. A BOLTZMANN frozen-potential closure
behaves differently (the standard gamma far off, a statistics-consistent gamma ~10x smaller closer but not
close): there gamma must absorb the degeneracy factor g ~ 14; with the FD closure in the Newton the degeneracy is in
the model and gamma is O(1).
