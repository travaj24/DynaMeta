## Usage

```python
from dynameta.constants import M_E
from dynameta.materials import DrudeOptical, Material
from dynameta.materials.transport_model import KaneBand, TransportModel

band = KaneBand(m0_kg=0.22 * M_E, alpha_per_eV=0.4)            # ONE object for the band
film = Material("FILM",
                optical=DrudeOptical(eps_inf=4.0, m_opt_kg=band.optical_mass(), gamma_rad_s=1.2e14),
                transport=TransportModel(n_bg_m3=3e26, eps_static=9.0, physics="equilibrium", band=band))
# 2-D: LayeredDevsimBuilder(design) solves the Kane closure in every equilibrium region of FILM
# 3-D: Stacked3DSpec.from_design(design) -> spec.bands == {"semi": band}; or Stacked3DSpec(bands={"semi": band})
# 1-D / hand-built: physics_equilibrium.setup_semiconductor_region(dev, reg, n_bg_m3=..., eps_static=..., band=band)
band.dos_mass_kg(3e26) / M_E        # 0.27317 (DOS mass reported to every consumer; T -> 0: m0 (1 + alpha E_F))
band.eta_of_density(3e26)            # 23.123 = (E_F - E_c)/kT of the closure at 300 K
```

## Derivations (brief)

- **Density.** n = (1/(3 pi^2)) Int (-df/dE) k^3 dE (integration by parts of the state count), k^2 = 2 m0 E (1 + alpha E)/hbar^2. With
  x = E/kT, b = alpha kT: n = N_c(m0) G, G = (1/Gamma(5/2)) Int f(x - eta) K'(x) dx, K = [x (1 + b x)]^(3/2); G(eta, 0) = F_1/2.
- **Why not the series of the plan.** G = F_1/2 + (15/4) b F_3/2 + (105/32) b^2 F_5/2 - (315/128) b^3 F_7/2 + ... (re-derived; the
  plan's coefficients are right) is the binomial series of (1 + b x)^(3/2) integrated term by term; once eta >> 1 its terms are
  ~ C(3/2, m) (b eta)^m, so it DIVERGES for b eta >~ 1 -- inside the requested range (b = 0.03, eta > 33; also b = 0.0103,
  eta = 58, b eta = 0.6, a strongly accumulated face). MEASURED with exact (quadrature) F_j: three terms err by
  5.5e-3 there (four terms -1.2e-3), and by 2.4e-2 (four: -9.7e-3) at b = 0.03, eta = 40. It would also need closed-form
  F_3/2 .. F_7/2. Not used.
- **Chosen evaluation.** Delta = G - F_1/2 exactly as an integral, evaluated (i) for eta <= 8 by generalized Gauss-Laguerre
  (weight x^(1/2) e^-x, N = 32, 22 nodes kept): Delta = (3/(2 Gamma(5/2))) Int x^(1/2) e^-x [e^eta/(1 + e^(eta-x))] g(bx) dx,
  g(t) = (1+t)^(1/2)(1+2t) - 1; (ii) for eta >= 6 by the Sommerfeld expansion to the 6th derivative, which for the Kane band
  closes exactly: with u = x(1 + bx), u'^2 = 1 + 4bu, K'' = (3/4)u^(-1/2) + 6b u^(1/2), K'''' = (9/16)u^(-5/2),
  K^(6) = (315/64)u^(-9/2) + (135/8) b u^(-7/2); (iii) a C2 quintic blend on [6, 8]. Every branch argument is clamped
  (min/max) so DEVSIM never evaluates an overflowing exp or a negative pow base. The closure is G = F_AH + Delta, so alpha -> 0
  is the parabolic closure (Delta = 0 exactly at b = 0, and the alpha = 0 band emits the parabolic model strings verbatim).
  DEVSIM differentiates the expression (`diff`, unsimplified: 13 ms for the whole region setup, no simplify cache needed).
- **Accuracy (MEASURED against scipy quadrature, eta in [-10, 60] step 0.25):** increment error |Delta - (G - F_1/2)| / G
  <= 1.5e-6 (b = 0.0103) / 3.5e-6 (b = 0.03), worst at eta = 7.5 (blend zone); other candidates measured: N = 24 / zone [5, 6.5]
  8.8e-6, N = 40 / [7, 9] 1.4e-6. The closure's total error against the exact Kane density is the Aymerich-Humet error of its
  parabolic part (max 3.8e-3 at eta ~ -3, 1.4e-3 at eta 15-20, 2.8e-4 at 60) plus < 4e-6: exactly the accuracy of the parabolic
  closure it extends. DEVSIM model vs numpy twin: 3.7e-15; DEVSIM analytic derivative vs central difference 2.4e-9 (the FD error).
- **Flat band, screening, DOS mass.** Phi_c0 = -V_t G^-1(n_bg/N_c(m0)) (bisection, shared kernel). L_s^2 = eps eps0 kT/(q^2 N_c
  G'(eta_bg)). DOS mass reported: m_d(n) = m0 (G/F_AH)^(2/3) at eta(n), the mass whose parabolic closure holds the same n at the
  same Fermi level (T -> 0: m0 (1 + alpha E_F), the counting mass; it is what `dos_mass_at_bg` and the 3-D spec report).
- **Optical mass.** m_opt = hbar^2 k_F/(dE/dk) at k_F = (3 pi^2 n)^(1/3) = m0 (1 + 2 alpha E_F) = m0 sqrt(1 + 4 alpha gamma_F):
  `KaneOpticalMass` (T = 0, degenerate). At finite temperature the f-sum mass (`carrier_heating.kane_mass_of_Te`) is heavier by
  thermal occupation: +0.20 % (m0 0.22 m_e) / +0.29 % (0.30 m_e) at 3e26 m^-3, 300 K. The Drude side keeps the T = 0 mass; the
  difference is reported, not changed. (m0 (1 + 2 alpha E_F) with the closure's 300 K Fermi level is -0.075 % from the T = 0 one.)
- **Not the SP band.** The Schrodinger-Poisson bulk limit N_c [F_1/2 + 2 b F_3/2] (parabolic z, in-plane Kane) is a different
  model: first-order coefficient 2 b vs 15/4 b. At 3e26 m^-3, alpha 0.4, 300 K: at the 3-D band's E_F the sub-band model holds
  0.8633 n_bg (m0 0.22 m_e) / 0.8903 n_bg (0.30 m_e); its own bulk E_F is 55.3 / 34.0 meV higher (0.6531 vs 0.5978 eV;
  0.4924 vs 0.4583 eV). Gated in `test_sub_band_model_is_a_different_band`; nothing equates them.

## Deviations from the plan / brief, and why

1. **Evaluation.** The plan's closed form (b-series with F_1/2, F_3/2, F_5/2) diverges inside the requested range (above); the
   exact-integral increment (Laguerre + closed-form Kane Sommerfeld, blended) replaces it. The plan's gate "closure vs quadrature
   to 1e-3 over eta in [-5, 40]" cannot hold for ANY closure that reduces to the present parabolic one at alpha -> 0 (the
   Aymerich-Humet fit alone misses by 1.5e-3 at eta = -5 and 1.4e-3 at eta 15-20); the gates are the increment (1e-5) and
   "closure error <= AH error + 1e-5".
2. **Files.** Beyond the plan's P13 list: `carriers/devsim_3d.py` (the brief's 3-D scope) and `screening_length_m` in
   `carriers/devsim_layered.py` (P4's request). `materials/__init__.py` and `dynameta/__init__.py` were NOT edited: `KaneBand`
   is imported from `dynameta.materials.transport_model` (request to P15: export it from `dynameta.materials` and the top level).
3. **Field name.** `KaneBand.alpha_per_eV` (the brief's spelling and carrier_heating's) rather than the plan's `alpha_eV`;
   `KaneOpticalMass` keeps `alpha_eV`, `from_band` maps it.
4. **Refusal.** DD / bipolar + KaneBand is refused at `TransportModel` construction (and in `Stacked3DSpec`), the earliest place;
   the builders need no extra check. `Stacked3DSpec` semiconductor INCLUSIONS (role semiconductor in a layer) stay parabolic.
5. **DOS mass.** "The DOS mass reported to anything that asks" is defined as the equivalent parabolic (counting) mass m_d(n);
   the closure itself never uses it (it uses N_c(m0) and the band).
6. **Newton tolerance.** The Kane closure's round-off floor on the potential update is ~1e-16 V (parabolic ~5e-17 V): DEVSIM's
   relative test |dx|/(|x| + 1e-10) at relative_error 1e-6 can fail at a zero potential where the parabolic one passes. The
   builders' default rel_tol (1e-5) and abs_tol in volts are unaffected; the 1-D tests use rel 1e-5.

## Not done / uncertain

- The finite-temperature optical (f-sum) mass is not wired into the Drude model (0.20-0.29 % at 300 K); KaneOpticalMass stays
  the degenerate mass.
- A Material-level check that a DrudeOptical's KaneOpticalMass matches the transport band is not added (`materials/material.py` is
  not a P13 file); `band.optical_mass()` gives the consistent object.
- FilmInterfaceTraps on a Kane film follow the closure's Fermi level automatically (they read `equilibrium_eta_expr`); no
  dedicated gate.
