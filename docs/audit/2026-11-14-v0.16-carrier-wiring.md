## Public inputs (usage)

```python
from dynameta.carriers.devsim_layered import LayeredDevsimBuilder
from dynameta.carriers.physics_traps import FilmInterfaceTraps
from dynameta.geometry import Electrode

design.electrodes += [Electrode("gnd", "film", "x_lo", role="ground")]          # Fermi reference (default)
# Electrode("gnd", "film", "x_lo", role="ground", pin_potential=True)          # v0.15.1 pinned column
# Electrode("top", "gate", "full", work_function_eV=5.1)                       # gate work function
b = LayeredDevsimBuilder(design,
                         fixed_charge={("film", "up_oxb"): -1.6e-3},           # C/m^2
                         bulk_charge={"up_oxb": 2.0e5},                        # C/m^3, dielectric only
                         interface_traps={("film", "up_oxb"): FilmInterfaceTraps(
                             dit_eV_m2=1e16, e_lo_eV=-0.6, e_hi_eV=0.6, neutral_level_eV=0.0)})
b.fermi_references()      # {"gnd": ["film"]}

from dynameta.carriers.devsim_3d import Stacked3DSpec
Stacked3DSpec(chi_semi_eV=4.5, gate_work_function_eV=4.7, fixed_charge={("semi", "oxide"): 1e-3},
              bulk_charge={"oxide": 2e5})
Stacked3DSpec.from_design(design, fixed_charge={("film", "lo_oxb"): 1e-3})   # Design layer names
```

the 32-point grid alike. `slice_eps_field` decides lateral uniformity with `np.allclose(v, v.mean(axis=(1, 2)),

mean over 256 x 256 samples is accumulated without pairwise summation and carries 1.75e-12 relative error
(MEASURED: the samples of every z slice are identical, ptp = 0; the same values in a C-contiguous array give
2e-16). With fewer lateral samples the test passes; the remaining spread (2.2e-13 with ExtrudeLift and
`grid_n_x=2`, 4.4e-13 with SeparableXYLift, MEASURED on a gated degenerate film of this kind; solver round-off
amplified where |eps| is small) is below 1e-12 but only by 2-5x, because near a zero of eps a relative test on eps amplifies round-off. Request to the core.layered
owner: compute the lateral mean on `np.ascontiguousarray(v)` (or compare to `v[:, :1, :1]` like the bridges'
`_y_invariant`), and consider an absolute floor relative to max |eps| of the slice. The new test runs with
`grid_n_x=2`, `lift="extrude"` until then.

## Plan / note statements found wrong or incomplete, and deviations

1. Plan C2 "an edge electrode creates no DEVSIM contact and sets EF_ref_V": extended to every equilibrium region
   CONNECTED to the electrode's region through semiconductor/semiconductor interfaces (otherwise an adjacent
   equilibrium layer without its own electrode keeps E_F = 0 while the referenced one moves, a battery at the
   interface). Gate: `test_reference_covers_every_connected_equilibrium_region`.
2. The two-voltage refusal covers pinned electrodes in a group with an unpinned one (one Fermi level either way);
   groups whose electrodes are ALL pinned keep the v0.15.1 behaviour (no new refusal), so `pin_potential=True`
   stays a bit-for-bit restore.
3. Plan P11 "fixed_charge keyed by interface or region name": `fixed_charge` takes interfaces, a separate
   `bulk_charge` takes regions (dielectric only: a bulk charge in a semiconductor would be a doping change). The
   sheet charge sits on the dielectric side (P5's routed `InterfaceTraps` fixed charge sits on the semiconductor
   side); the box-method result is side-independent (MEASURED 6.7e-16 between the two on the gated-film fixture).
4. Work function: the ramp and the zero-bias seed now run in the APPLIED potential (bias + offset), seeding a
   work-function gate at 0 and ramping to its offset; this makes "work function = bias shift" exact (bit for bit)
   through the builder, not only on P5's hand-built device. Arithmetic is unchanged for every electrode without
   a work function.
5. A work function on an electrode whose contact lands on a semiconductor raises (a Schottky contact is not
   modelled); the plan did not cover it.
6. 3-D (plan: "refuse or wire; measure, then decide"): the primitives work unchanged in 3-D (MEASURED above), so
   `fixed_charge` / `bulk_charge` (any physics), `FilmInterfaceTraps` (equilibrium) and the gate work function
   (equilibrium) are WIRED. The work function is refused (NotImplementedError naming the 2-D builder) for the
   drift-diffusion and bipolar 3-D bodies, whose gate is referred to a different neutral level (bipolar: the
   intrinsic level plus phi_bi) that would need its own derivation and gate. `from_design` refuses a work
   function on any electrode other than the gate (the spec does not model it).
7. The 3-D builder's body contact is a face contact under the semiconductor, not an edge electrode; C2 does not
   apply to it and `Electrode.pin_potential` of a Design's ground is not read by `from_design` (unchanged
   geometry, outside this package).
8. C5 guard call sites: `devsim_layered.py:703, 890` of the plan are now `build_device` and `_hetero_side`;
   `devsim_3d.py:559, 626` are both in `from_design` (a hand-built `Stacked3DSpec` takes a float mass). P4's
   `screening_length_m` still evaluates the callable directly (same float; the warning comes from the build).
9. P5 note 3 listed `_trap_noise_child.py` among the files to adapt: its fast tests do not build the validation
   device through a builder and passed unchanged.
10. P4's end-to-end follow-up exposed the slicer finding above; the test works around it (grid_n_x=2, extrude
    lift) rather than touching `core/layered.py`.
