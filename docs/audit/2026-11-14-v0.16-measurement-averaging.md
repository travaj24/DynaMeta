# v0.16 package: measurement averaging (owner-requested addition)

numpy 2.4.4, scipy 1.17.1,
NGSolve 6.2.2608 (end-to-end example only), Python 3.14, Windows, BLAS / NGSolve pinned to 2 threads on
a shared, loaded machine (wall times indicative).

Purpose: turn ideal plane-wave, perfectly periodic optical solves into what a reflectance measurement
of a fabricated grating records, so that broadening from the measurement (cone, spectrometer) and from
fabrication scatter can be separated from intrinsic material loss. A thin layer over the existing
optical-solver interface: no new solver, opt-in, and nothing in the library calls it.

#   or any callable  model(wavelengths_m, theta_deg=, phi_deg=, pol=, **params) -> r  (or (r_co, r_cross))

setup = MeasurementSetup(
    pupil=pupil_quadrature(0.3, mode="in_plane", fold_symmetric=True),   # filled NA 0.3 objective
    parameters=parameter_quadrature("width_m", "normal", mean=160e-9, std=5e-9, n_nodes=7),
    scatter_collection="all",            # objective collects the diffuse cone: <|r|^2>
    detection="power",                   # incoherent source / bucket detector
    instrument=InstrumentFunction("gaussian", fwhm_m=5e-9),
    reference=mirror_model,              # reflectance = conv(S)/conv(S_mirror) x R_mirror
    period_m=400e-9)                     # warns if a diffracted order enters the pupil

res.signal, res.detected, res.amplitude, res.specular, res.incoherent, res.diffuse, res.notes

fit = fit_broadening(lams_nm, R_meas, surrogate, p0, sigma=2e-3, null_values={"gamma_extra": 0.0})
fit.params, fit.stderr, fit.correlation, fit.degenerate, fit.null_tests, fit.message

## Physics choices, and why

**Cone (item 1).** Directions are labelled by s = k_par/k0 = n sin(theta) in the incidence medium,
with d^2 k_par = (n k0)^2 cos(theta) dOmega. A filled pupil (aplanatic objective or Koehler condenser,
sine condition) is uniform per d^2 s, i.e. power per solid angle proportional to cos(theta); a Gaussian
beam is exp(-2 s^2/s0^2) per d^2 s, with s0 either fixed in the pupil (`na_e2`) or set by a fixed focal
waist (`waist_m`, s0 = lambda/(pi w0), so the weights change with wavelength and are handled per
wavelength). A linear input at lab angle a splits on the ray at azimuth phi into a_p = cos(a - phi)
(radial -> p) and a_s = sin(a - phi) (azimuthal -> s) (Richards-Wolf). The return field in the pupil
is E_ret = (a_s r_ss + a_p r_sp) phi_hat - (a_p r_pp + a_s r_ps) rho_hat (the p part returns along
-rho_hat with the Byrnes reflected p-hat), so E_par = a_s^2 r_ss - a_p^2 r_pp + a_s a_p (r_sp - r_ps)
and E_perp = a_s a_p (r_ss + r_pp) + a_p^2 r_sp + a_s^2 r_ps. At normal incidence E_par = r_s: NA -> 0
is the plane wave exactly (one node, weight 1).

Which solvers can do the conical part: the 3-D FEM, the RCWA bridge (2-D lattice) and the PMM bridge
(both via the rotated s/p synthesis, lossless end media), and for planar stacks the layered TMM and
Berreman solvers. None returns the cross-polarized specular amplitude at conical incidence through
`OpticalResult` (the FEM's `r_cross` is normal incidence only), so a conical average with them neglects
s<->p conversion and the result says so in `notes`. The 2-D TM FEM and the PMM2D bridge are in-plane
only; for them `mode='in_plane'` is the labelled approximation: each ray is replaced by the in-plane ray
with the SAME k_x and k_y is dropped; the input splits into TM (cos a) and TE (sin a). The 2-D pupil
integral then reduces exactly to a 1-D integral over s_x with the marginal weight (a semicircle for a
filled pupil; Gauss-Legendre after s_x = NA sin t removes its square-root end point). Keeping k_x (not
the polar angle) is the right first-order choice for a grating-coupled resonance (k_x + mG = beta(k_y),
even in k_y); the dropped k_y and the focal depolarization enter at O(NA^2). Measured on a thin film
(worst case: TE and TM differ strongly off normal), the in-plane approximation errs by 5.8e-3 on
R = 0.043 at NA 0.5 (13 % relative), scaling as NA^2.

**Detection models (item 1(a)/(b)), not conflated.**
(a) Extended incoherent source: every direction reflects independently; S = sum_k W_k |E_ret,k|^2
(`detection='power'`, optional analyzer). (b1) Coherent focused beam on a bucket detector: by Parseval
the collected power is INT |J(s) A(s)|^2 d^2 s, the SAME intensity sum with W = |A|^2 -- valid while no
non-specular order enters the collection pupil (lambda/period > 2 NA; otherwise an order from s lands on
the specular ray of s + mG and interferes; `period_m` warns). (b2) Interference with a reference, or
coupling into a single mode matched to the illumination: the mode overlap INT A* . B d^2 s, i.e. the
COHERENT AMPLITUDE AVERAGE r_coh = sum_k W_k E_par,k (`detection='amplitude'`, signal |r_coh|^2). This
is what a phase measurement records. Every run computes both from the same solves (`res.amplitude` is
always there), so they can be compared at no cost.

**Fabrication scatter (item 2).** Local-patch picture: for a slowly varying parameter the specular
FIELD of all patches adds coherently, so a specular detector small compared with the diffuse cone
(half-angle ~ lambda/(nL)) records |<r>|^2 (`scatter_collection='specular'`); <|r|^2> - |<r>|^2 = Var r
goes into the diffuse cone and is recorded only by a detector that collects it (an objective with NA >>
lambda/L, an integrating sphere: `'all'`). The choice is REQUIRED when scatter is given with power
detection (a ValueError says why). Mode-matched coherent detection always sees <r> (the overlap is the
intensity-weighted spatial average of r). Both powers and the diffuse part are always returned.
Validity stated in the docstring: L >> lambda, L >> period, L >> the mode's lateral propagation length,
illuminated area >> L. Sub-wavelength variation and period-to-period disorder are not this picture and
are not modelled. Quadrature: Gauss-Hermite (normal), Gauss-Legendre (uniform), samples, user nodes;
several parameters by tensor product (cost prod n_i) or Smolyak (exact to total degree 2(L-d)+1; with
non-nested Gauss rules it only pays from ~4 parameters: 13 vs 9, 25 vs 27, 41 vs 81, 61 vs 243 nodes for
d = 2..5 at total degree 5). `convergence_nodes` re-runs at another order and warns
(`UnreliableResultWarning`) above `convergence_tol`.

**Reference amplitude (release fix).** A coherent amplitude is normalized as amplitude / (reference amplitude
under the same cone) x r_reference, which needs the reference's COMPLEX amplitude. 'plane_wave' takes it from the
reference model, `reference_amplitude=` gives it with a numeric `reference_reflectance=abs(r_ref)**2`, and None
returns the raw ratio (phase relative to the reference). A numeric power reflectance alone fixes |r_ref| but not its
phase (a metal mirror has r close to -1): amplitude detection then raises ValueError and power detection returns
amplitude = NaN. (Taking sqrt(R_ref) as the reference amplitude returned -(0.3+0.4i) for a sample 0.3+0.4i against a
r = -0.98 mirror: a pi error.)

**Spectrometer and normalization (item 3).** The detected POWER is convolved (a complex input raises
TypeError) with a unit-area Gaussian, Lorentzian, triangular (equal slits) or rectangular (single slit)
line shape, in wavelength (`fwhm_m`) or wavenumber (`fwhm_per_cm`), computed exactly for the
piecewise-linear interpolant of a non-uniform grid (closed-form kernel antiderivatives per interval; no
resampling). A non-flat lamp is handled as conv(S I0)/conv(I0); a reflectance is conv(S)/conv(S_ref) x
R_ref with the reference detected under the same cone. `edge='renormalize'` (default) preserves
constants to the grid ends; `edge='zero'` conserves the integral exactly.

**Finite array (item 4).** Documented as an effective cone (k_x spread ~ 2 pi/(N period), item 1 with
mode='in_plane' and the aperture's far-field profile); no separate model. Edge leakage of a mode whose
propagation length exceeds the array is a loss channel, not an angular average, and needs a
finite-array solve.

**Composition (item 5).** Fields first (per ray, per parameter node, per wavelength), then the patch
average, then detection and the angle sum, then the instrument on the detected signals, then the
reference ratio. `plan()` gives the number of model calls and plane-wave solves before solving
(`max_solves` refuses above a limit); `n_workers` (thread pool) or `map_fn` (any map, e.g. a process
pool with a picklable model) parallelize the calls; results are bit-identical to serial (gated). NGSolve's
task manager is process-global, so NGSolve-backed models should use `n_workers=1` or a process pool.

**Fit (item 6).** `fit_broadening` runs a scaled least-squares fit and judges from the Fisher matrix:
exactly singular directions (only a combination measurable, infinite errors), parameters not resolved
from zero (|value| <= 2 sigma), and pairs with |corr| >= 0.95 that are DEGENERATE FOR THESE DATA only when
one of them is unresolved. Correlation alone is not the verdict: a Gaussian and a Lorentzian width are
correlated at -0.963 on a single dip (measured; independent of the noise level, as Fisher correlations
are) yet both were resolved to ~2 % at 2e-3 noise. `null_values={'gamma_extra': 0}` answers the question
directly (delta chi2 of the refit without the extra damping; < 4 = not required). `fano_fit` /
`lorentzian_fit` were not reused for the fit itself because they reduce a line to ONE width, so they
cannot separate mechanisms; they are used to quote the measured linewidth.

## End-to-end example (validation/measurement_strip_broadening.py)

Cell (2-D TM FEM, order 4 default): Au strips (Drude eps_inf 9.84, hbar wp 9.01 eV, hbar gamma
0.072 eV) 200 nm wide, 40 nm tall, period 400 nm, on a 10 nm spacer (n 1.45) over a 100 nm Au mirror on
glass; air above; E across the strips. 36 wavelengths 1250-1950 nm. Dip position from
`analysis.resonance_dip`, linewidth = FWHM of `analysis.fano_fit`, diffuse = <|r|^2> - |<r>|^2 at the dip.
The cone uses the labelled in-plane approximation (the solver is in-plane TM only), 9 k_x nodes folded to 5
solves; width scatter is normal, Gauss-Hermite 9 nodes (11 at 10 nm). Measured 2026-11-15 (all four scripts).

What this says:
- **The cone cannot broaden this dip.** The gap-plasmon resonance under a strip is localized and
  nearly independent of k_x: up to NA 0.5 the dip moves 0.5 nm, its depth changes by 1.1e-3 and its
  FWHM by +0.5 nm. Power and coherent-amplitude detection agree to 4 digits because r hardly varies
  across the cone. (Caveat: in-plane approximation; the k_y and TE parts of the cone are not in this
  number. A grating-coupled, dispersive mode would behave very differently: the thin-film and
  displaced-mirror tests show both models' sensitivity.)
- **Width scatter broadens strongly**, because the dip moves d(lambda)/dw = 6.8 nm per nm of width:
  2 / 5 / 10 nm std give FWHM 197 / 224 / 303 nm (+3 / +17 / +59 %). With full collection the dip also
  becomes SHALLOWER (R 0.051 -> 0.275); with specular collection it becomes DEEPER (-> 0.013 at 5 nm,
  0.004 at 10 nm), because the patch fields add coherently and partly cancel: the missing power (diffuse
  0.03 / 0.13 / 0.27 at the dip) leaves the specular direction. A shallower-and-broader dip is the
  signature of an objective-collected scatter measurement; a deeper-and-broader one of a small-aperture
  specular measurement; intrinsic extra damping makes the dip broader and (past critical coupling)
  shallower in both. The dip position barely moves (symmetric scatter; +0.8 / -0.7 nm at 10 nm, where
  the dip's nonlinear width dependence starts to show).
- Independent check (gate F): the full-collection FWHM at 2 and 5 nm matches the Voigt width built
  from the plane-wave FWHM and d(lambda)/dw (from two extra plane-wave spectra at w +- 5 nm) to +0.1 %
  and +1.1 %.
- A Gaussian spectrometer of 10 / 30 nm FWHM adds only 2.0 / 6.7 nm to this 191 nm line.

Gates: A NA = 0 equals the direct solve (|dR| = 0); B cone converged (n_kx 9 vs 11: 1.7e-8); C scatter
converged at 10 nm (11 vs 13 nodes: 3.2e-4); D |<r>|^2 <= <|r|^2> and |r_coh|^2 <= power everywhere
(0 violations); E full-collection FWHM and R grow with std and the specular dip is never shallower; F
Voigt width within 5 %. All four scripts PASS (walls 507 / 488 / 498 / 631 s at 2 threads).

Two expectations in the first draft of this script were WRONG and were removed rather than tuned:
"the FWHM grows with NA" (it does not for a localized mode) and "the plane-wave dip is the deepest"
(specular collection of a scattered sample is deeper).

### Split for the per-script cap (2026-11-14, full-run fixes)

The unsplit script measured 2487 s in a later run on the same box and TIMED OUT at run_all's 2700 s
per-script cap in a shard run (the cap exists to catch hangs and was not raised). Two changes, no gate or
tolerance changed:

1. Identical solves are no longer repeated. Each solve re-meshes (buffers and PML scale with the
   wavelength), so nothing is shared across wavelengths, but the normal-incidence nominal-width spectrum
   is also the k_x = 0 node of every cone rule and the centre node of every odd Gauss-Hermite width rule
   (both exactly 0.0, checked). `StripModel(cache=True)` memoizes r(lambda, theta, width) in-process; the
   FEM solve is deterministic (a repeat is bitwise equal), so this changes no number. Gate A compares
   against `StripModel.direct()`, which always solves fresh. 288 of the 2379 solves were such repeats.
2. Split by gate group into four scripts, each importing the shared driver (`Study`) from the first:

| script | cases | gates | solves | wall (dev box, 2 threads) |
|---|---|---|---|---|
| `measurement_strip_broadening` | plane wave, NA 0.1 / 0.3 / 0.5 (power + amplitude), n_kx 11 check, instrument rows | A, B, D | 651 | 507 s |
| `measurement_strip_scatter` | plane wave, std 2 / 5 nm, w -+ 5 nm spectra | D, E1, F | 684 | 488 s |
| `measurement_strip_scatter_wide` | plane wave, std 5 / 10 nm | D, E2 | 684 | 498 s |
| `measurement_strip_scatter_conv` | plane wave, std 10 nm with the 13-node refinement | C, D | 828 | 631 s |

Gate E (FWHM and R_min strictly grow along plane wave < 2 < 5 < 10 nm; specular never shallower at
2 / 5 / 10 nm) is checked as its consecutive links, E1 (plane wave, 2, 5 nm) and E2 (5 -> 10 nm), whose
conjunction is exactly the original assertion. Gate D runs in every part over that part's spectra (their
union is every spectrum of the unsplit script). The std 5 and 10 nm cases are recomputed where two groups
need them (same solves, same values); the 10 nm primary rule in `_scatter_wide` runs without the
refinement, which does not change the primary result. Times above are on a lightly loaded box (0.73-0.77
s per solve); at the 1.04 s per solve of the run that timed out, the slowest part is ~870 s.

At the split every gate value and table entry of the four parts equalled the unsplit run digit for digit
(the solves are deterministic and the cache only removes repeats).

## Requests to other owners

1. Bridges / FEM (`OpticalResult`): expose the full specular Jones matrix (r_ss, r_sp, r_ps, r_pp) in
   the rotated s/p basis at conical incidence (the RCWA/PMM per-order amplitudes already contain it;
   `_common.conical_synthesis` projects it onto the co-polarized direction only). The conical cone
   average would then include s<->p conversion instead of neglecting it; the model protocol already
   accepts `(r_co, r_cross)`.
2. 2-D TM FEM: a TE (E along the lines) companion would let the in-plane mode treat inputs not
   perpendicular to the lines (a != 0) with the same solver.

## Left undone / uncertain

- The conical path with library solvers neglects polarization conversion (request 1). For a 1-D grating
  under a cone this is a first-order amplitude effect at off-axis azimuths; its size was not measured
  here because no available solver returns it.
- The in-plane approximation is O(NA^2) and was quantified on a thin film only (13 % relative at NA 0.5,
  the TE/TM-contrast worst case); for the strip grating its error was not measured (needs a conical
  solver with cross terms), so the "cone cannot broaden this dip" conclusion holds for the k_x part of
  the cone only.
- The scatter rows assume the local-patch picture; for this localized mode the lateral decay length
  is short (sub-period), so a correlation length of a few periods suffices, but that was not checked
  with a supercell solve.
- The local-patch scatter model is not valid for sub-wavelength or period-to-period disorder; nothing
