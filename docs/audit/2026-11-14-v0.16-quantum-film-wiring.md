## 1. Public API and end-to-end use

```python
from dynameta.carriers import DualGateSchrodingerPoisson, GateStack
from dynameta.constants import M_E
from dynameta.materials import Material, MaterialRegistry, ConstantOptical
from dynameta.optics.quantum_film_pipeline import QuantumFilmOptical, QuantumFilmCoupling, run_quantum_film_pipeline
from dynameta.optics.fem_2d_tm import make_fem_2d_tm_optical_solver     # or the PMM / RCWA / Berreman seams

reg.add(Material("FILM", QuantumFilmOptical(eps_inf=4.0, gamma_rad_s=1.2e14, xc="none")))   # the flag + options
# design: ... Layer("film", 6e-9, "FILM") ... under a lamellar grating
ox = GateStack(((2e-9, 9.0), (6e-9, 20.0)))
s = DualGateSchrodingerPoisson(t_film_m=6e-9, bottom=ox, top=ox, n_bg_m3=3e26, m_eff_kg=0.30 * M_E, eps_static=9.0,
                               nz=481, semi_material="FILM")
rows, coupling = run_quantum_film_pipeline(design, sweep, s, film_layer="film",
                                           optical_solver=make_fem_2d_tm_optical_solver())
coupling.response(bias, reg.get("FILM").optical)          # the exact QuantumFilmResponse behind a row
coupling.effective_layer(bias, opt, lambda_m)             # (eps_xx,eq, eps_zz,eq, L): what the optics received
```

Equivalent with plain `run_pipeline`: `c = QuantumFilmCoupling(s); run_pipeline(design, sweep, carrier_solver=c,
extra_fields=c.extra_fields, optical_builder=film_layer_optics(design, "film", c), optical_solver=...)`.
By hand (bit-identical, gated): `film = QuantumFilm.from_dual_gate(s, s.solve_voltages(Vb, Vt))`;
`exx, ezz, L = QuantumFilmResponse(film, 4.0, 1.2e14).effective_layer(2 pi c / lambda)`;
`optical_solver(design, None, {"film": EpsField(tensor=np.diag([exx, exx, ezz]))}, lambda, n_super, n_sub)`.

How it flows. The film's permittivity is not a function of the density: it needs the whole ground state. So
`QuantumFilmOptical` declares `field_response` / `needs_position` (the P17 surface) and reads the per-bias
`QuantumFilmState` from the field bundle (`extra_fields`, key `quantum_film_state`); it returns the equivalent
layer as ONE uniform (3, 3) tensor, which `assemble_eps` turns into a uniform tensor EpsField. Guards: the state
must belong to the carrier solution being assembled (density column and stack-axis span compared), the film
layer's thickness must equal the carrier film's (`film_layer_optics`), `eps()` without a state raises (a
quantum film in a fixed-eps region fails loudly), the reserved key is refused in user extra fields.

Caching. The coupling is a CarrierSolver around the dual-gate solver (its bias cache and warm starts are used
unchanged); per gate-voltage pair it builds the complete sub-band set once; per (bias, option set) one
`QuantumFilmResponse` (the frequency-independent collective modes, 1.1 s at 481 nodes / 2380 pairs); per
wavelength only the sheet responses (< 1 ms). Gated: 3 biases x 2 wavelengths = 3 dual-gate solves, 3 states,
1 response per bias, 2 layer evaluations per bias; a repeated sweep builds nothing. Fingerprints: the option set
is the frozen `QuantumFilmOptical`, whose repr names eps_inf, both damping rates, xc, eps_xc, occupation_tol,
route and max_pairs_modes; `dynameta.cache` keys a material it cannot evaluate by its repr, so 8 option variants
give 8 keys (gated); `QuantumFilmCoupling.cache_fingerprint` names the carrier-side inputs.

## 3. The exact reference for structured cells (`optics.quantum_film_cell`)

Why not the FEM extension hook. The out-of-plane kernel sigma_zz(z, z') couples every pair of points of a film
column; NGSolve symbolic forms are pointwise. Two hook realizations were considered and rejected: (a) auxiliary
fields depending on x only (mode or low-rank amplitudes of P_z) -- the structured mesh has no x-only space without
a solver-core change, and the kernel is full rank (476 of 480 singular values above 1e-10 on the 6 nm generic film,
481 nodes; no low-rank shortcut); (b) a local Sternheimer system for the perturbed sub-band states on the film
subdomain -- its finite-element ground state would differ from the Schrodinger-Poisson finite-difference model at
O(h^2), which can exceed the planar first-order error being tested (1e-7 to 9e-7 for symmetric films).

What was built instead (same physics, exact within it). The film is laterally uniform and its response is
laterally local (q -> 0), so lateral harmonics do not mix in the film: harmonic m (q_m = k_x + 2 pi m / P)
crosses it through the exact planar element `QuantumFilmResponse.transfer_matrix(omega, q_m)`. The cell solver
is a 2-D periodic TM FEM (H_y, its own structured mesh with geometric corner grading, Bloch factor taken out)
over the patterned layers, with exact Fourier ports: the superstrate radiation condition on top, and on the
bottom line (inside the upper oxide, 5 nm below the strips) the exact per-harmonic admittance of the laterally
uniform stack below (built upward from the substrate one 2 x 2 layer at a time; a layer with evanescent decay >
e^-35 is a half-space). One sparse LU per wavelength; any stack below (another bias, another film model) is a
rank-(2M+1) Woodbury update. Film absorption = the per-harmonic Poynting-flux difference across the film (exact
for the discrete element, whose discrete Poynting theorem holds); FEM-region absorption = volume integrals;
energy closes independently. Exactly treated film harmonics |m| <= M_f (40), the equivalent layer beyond (its
field there decays exponentially with |m|; converged, gate C).

Validation of the reference (`validation/quantum_film_strip.py`, `tests/test_quantum_film_cell.py`), re-measured on
the generic strip cell (2026-11-15):

## 4. The equivalent layer inside the structured cell

The generic strip cell (re-measured 2026-11-15): metal strips (eps -60+4i) 150 nm wide, period 400 nm, 40 nm tall, on
2 nm oxide A (n 1.70) / 6 nm oxide B (n 2.00) / 6 nm film / 6 nm oxide B / 2 nm oxide A over an 80 nm mirror metal
(eps -120+20i) on glass (n 1.45), air above, TM, normal incidence. Film 3e26 m^-3, m* 0.30 m_e, eps_static 9.0,
gated through 2 nm (static eps 9) + 6 nm (static eps 20) on both faces (dual-gate SP, 481 nodes, laterally uniform
as that solver is), eps_inf 4.0, damping 1.2e14 rad/s, RPA. Metal permittivities constant over the band (fixture
simplification). Cell solver order 5 / 150 port harmonics / 8 grading levels, 80 exactly treated film harmonics
(both converged, gates C, D).

Reading. (1) The strips amplify the equivalent layer's error ~500-700x over the planar stack for symmetric gating
(~100x one-sided; resonant gap mode, 34-55 % of the light absorbed in the film). (2) It is NOT the specular
first-order error that is amplified: treating only m = 0 exactly removes < 1 % of it for symmetric gating (3-4 %
one-sided). The error lives in the lateral harmonics, where the first-order layer degrades with q L: per harmonic
its transfer matrix differs from the exact element by 3e-5 at q = 0, 5e-5 at q = 1e7 /m, 7e-3 at q = 1e8 /m
(q L = 0.6), 0.08 at 3e8 /m (flat band, 1200 nm, max relative element difference). (3) One-sided gating is 3-9x
worse (an asymmetric film's response position along z, absent from a uniform layer, enters at the order where the
structure couples). (4) Bias-induced changes are reproduced well: the error is 0.5-5e-3 in r against a bias
modulation of 0.09-0.18 in r.

Over the full band (section 6) the equivalent layer stays within 7.4e-4 .. 9.6e-4 of the exact film in R for
symmetric gating and 1.6e-3 / 2.7e-3 for one-sided gating; dip positions within 0.1-0.2 nm (symmetric) and
0.4-0.7 nm (one-sided), dip depths within 3e-4, FWHM within 0.4 nm, bias shifts within 0.6 nm.

Verdict on the equivalent layer for this device class: adequate for dip position, depth and bias shift (errors far
below the bias modulation and below the RPA's own model uncertainty -- the P7 note measured xc changing A by up to
0.0009 in a planar stack); not adequate when r must be
right to better than ~1e-3 (symmetric) / ~5e-3 (one-sided). For those, use `optics.quantum_film_cell` (exact per
harmonic) on lamellar cells: ~1.6-1.9 s per (bias, wavelength) for the film harmonics plus ~6 s per wavelength for
the FEM factorization.

Evidence (exact film, 1200 nm, per-harmonic data of the cell solver; k_F from the peak density, v_F = hbar k_F / m;
generic strip cell):

| (0, 0) | 2.29 | 1.78 | 0.016 / 0.031 / 0.079 | 0.079 | 1.7e-4 | 2.8e-4 | 1.4e-5, -1.5e-6 |

| (0, +3) | 2.62 | 1.55 | 0.016 / 0.031 / 0.079 | 0.079 | 1.3e-4 | 3.7e-4 | 1.8e-5, -4.1e-6 |

(<.>_A: average over harmonics weighted by the film's absorbed power per harmonic. Lindhard term: each sub-band's
in-plane Drude weight multiplied by the 2-D high-frequency factor 1 + (3/4)(q v_F,i / omega)^2 per harmonic -- the
leading in-plane finite-q correction -- computed in the cell solver; `validation/quantum_film_strip.py`.)

The film field is dominated by the first few lateral orders (m <= 2 hold 90 % of the film absorption, m <= 5
hold 99 %): the 8 nm of oxide between the strip corners and the film filters the edge near field, whose
amplitude at the film decays as exp(-q d). The largest relevant q is ~0.08 /nm: q/k_F <= 0.04 and
q v_F/omega <= 0.05, so the dropped terms are ~ their squares, absorption-weighted 1-4e-4. The leading in-plane
correction, computed, moves r by 1.2-1.8e-5 and A_film by < 4.1e-6 -- 30-400x below the equivalent layer's error.
The out-of-plane (intersubband) dispersion was NOT computed; its natural scale, the finite-q spread of the
transition frequencies q v_F / 2 ~ 1.4e13 rad/s at the 90 % point (3.5e13 at 99 %), is below the damping (1.2e14
rad/s), so near the collective resonance its relative effect is ~ (q v_F / 2 gamma)^2, i.e. ~1-2 % of the (itself
small) high-q contribution -- an estimate, not a calculation.

Assessment: the q -> 0 approximation HOLDS for this cell (estimated and partly computed errors ~1e-5 in r, below
every other error here). It would fail for a film much closer to the metal (d of 1-2 nm, so that q ~ 1 /nm carries
field), for nanometre gaps, or at much lower density (smaller k_F and omega/v_F). What it would need then: the
finite-q RPA, chi0(q, z, z'; omega) with the 2-D Lindhard function of each transition (in-plane dispersion and
Landau damping). It drops into the same per-harmonic architecture: a `FilmLayer` whose matrix uses a q-dependent
response kernel (`response_kernel(omega)` becoming `response_kernel(omega, q)`).

## 9. Left undone / uncertain

- The hook-based exact extension inside `optics.fem_2d_tm` was not built (reasons in section 3); the exact
  reference is a separate solver that shares no FEM code with it. It handles lamellar cells with laterally
  uniform layers below the patterned ones; a film INSIDE a patterned layer, or patterned layers below the film,
  are not covered (they would need the harmonic coupling inside the stack, i.e. an RCWA-type layer).
- The run_pipeline route always hands the optics the EQUIVALENT layer; no `optical_solver` seam for the exact
  film (an EpsField cannot carry the kernel). The exact route is `FilmCell` / `QuantumFilmResponse.stack_rt`.
- Gating is laterally uniform (the dual-gate solver); strips acting as a patterned top gate would need per-column
  films (QuantumFilmResponse.validity names this).
- The out-of-plane finite-q correction is estimated, not computed (section 5).
- The classical graded Drude film reaches the 2-D FEM through the pipeline on its native 401-sample grid with
  4 identical lateral columns, which the Design adapter routes through the laterally STRUCTURED voxel path (it
  does not collapse identical columns): correct but heavier. Not changed (a behaviour change of the adapter
  for existing inputs would need the rule-4 restore/A-B machinery); REQUEST to the P10 owner / P15: collapse
  laterally identical columns to the native z path, with a restore keyword.
- PMM default (degree 16) and RCWA default truncation converge slowly on the metal-strip cell (algebraic TM
  corner convergence; P3 and another package's factorization work).
- Bitwise gates (the PMM A/B) were run on this workstation only (rule 2: confirm on CI).
- `validation/quantum_film_strip.py` and its band parts `_sweep_mid` / `_sweep_long` (ngsolve, 385-485 s each
  after the 2026-11-14 split, 480-510 s on the generic fixture) are not in run_all's SMOKE tier; they need a
  solver stack, so they are outside the
  smoke curation by construction.
