## Part 1: finite barriers

**Discrete BenDaniel-Duke operator.** Interfaces sit ON grid nodes; materials are per cell [z_j, z_j+1]
(inverse mass 1/m_j+1/2, permittivity), the band offset per node. Integrating
-hbar^2/2 d/dz((1/m) dpsi/dz) + U psi = E psi over the control volume [z_j - h/2, z_j + h/2] with the flux
(1/m) dpsi/dz taken as the cell difference gives row j:
-(hbar^2/2h^2)[(psi_j+1 - psi_j)/m_j+1/2 - (psi_j - psi_j-1)/m_j-1/2] + U_j psi_j = E psi_j, with U_j the
control-volume average (V_b/2 on the interface node). This is linear finite elements with mass lumping: the
discrete flux is single-valued at every cell face (the BenDaniel and Duke 1966 condition (1/m) psi'
continuous, enforced in the limit h -> 0 at the interface node), the matrix is real symmetric (Hermitian
under the uniform weight h), and the eigenvalues converge at O(h^2). The pre-0.16 node-mass form (harmonic
mean of node masses per face) cannot represent a step at a node and is first order (measured below).

**Poisson and the boundary condition.** Electron charge in the penetration region is a Poisson source,
so the oxide is no longer charge-free up to the film face. The Schrodinger-Poisson domain is extended by a
whole number of film cells, d = N_pen h, into each oxide stack; inside it Poisson is in control-volume form
with per-cell permittivity (a cell straddling a layer boundary gets the harmonic mean, exact for the
constant flux of a charge-free cell; the mass is length-averaged for the same reason, offsets are
control-volume averaged); the interface node carries half the film doping, and the fixed interface charge
and the trap charge become sheet sources Q/h on the interface node (they sit on the interface plane, now
inside the domain). Beyond the end of the penetration region the remaining oxide is charge-free (any
number of layers, the first one possibly partial), so its displacement is uniform and it acts as the series
capacitance C_rem = 1/sum(remaining t_i/(eps0 eps_i)). The Gauss matching plane is the domain end:
bottom C_rem,b (phi_m,b - phi_gb) - F_m,b = 0, top F_m,t + C_rem,t (phi_m,t - phi_gt) = 0, with F_m the
conservative half-cell flux of the end node (`sp_face_flux_C_m2` with the end cell's permittivity; n = 0
(psi = 0 at the wall) and N_d = 0 there). The two matching-plane potentials are the outer Newton unknowns;
the tangent predictor uses C_rem. If the penetration reaches the gate (C_rem infinite) the residual becomes
C_ref (phi_m - phi_g) (C_ref = eps0 eps_end / h, a scale only) and the gate charge is -F_m,b / +F_m,t.
Summing all control volumes gives the exact discrete balance
Q_gate_b + Q_gate_t + sigma_b + sigma_t + Q_it,b + Q_it,t + q trapz_domain(N_d - n) = 0.
A face with no barrier (or `penetration_m=0`) keeps the hard wall and the old face law; a solver with no
active option takes the old code path.

**Penetration depth.** `OxideBarrier(height_eV, mass_kg, penetration_m=None)`; height and mass scalar or per
layer (layers from the film outward). Default: the depth at which int kappa dz = ln(1e16)/2 with
kappa = sqrt(2 m (V_b - E_F - 10 kT))/hbar per layer at flat band (density tail 1e-16 = round-off), rounded
up to a cell, capped at the stack. A barrier at or below E_F + 10 kT is refused. Diagnostics at every
converged bias: `UnreliableResultWarning` when the oxide band (offset - q phi) comes within 5 kT of E_F
inside the penetration region (tunnelling regime: the closed one-Fermi-level model with a wall at the
matching plane confines classically allowed states -- in reality they belong to the gate's reservoir);
`AdvisoryWarning` when the density next to the wall exceeds 1e-6 of its maximum.

**Infinite-barrier limit (measured, oxide mass = film mass, 0.5 nm penetration, asymmetric stacks with
offsets and interface charges, 241 nodes, (1, -1) V).** Two regimes: while the tail is resolved
(kappa h < 1) the difference to the hard-wall solver falls as V_b^-1/2 (continuum penetration length):
6.09e-2 / 1.85e-2 V at 10 / 100 eV (ratio 3.30 per decade; 4.17e-3 V at 1e3 eV); once kappa h >> 1 the
interface node is pushed to zero and the discrete operator becomes the hard-wall one, so the difference
falls as 1/V_b: 5.40e-4 / 5.59e-5 / 5.62e-6 V at 1e4 / 1e5 / 1e6 eV (ratios 9.65 / 9.96), density
1.72e-3 / 1.78e-4 / 1.79e-5 n_bg. A zero `penetration_m` or `barrier=None` is the existing path, bit for bit.

## Part 2: exchange-correlation in the ground state

`xc="x"` (exchange) or `"lda"` (exchange + Perdew-Zunger 1981 correlation, unpolarized), `xc_eps_r`
(default the film's static eps_static). Effective atomic units of the host: a* = 4 pi eps0 eps_xc
hbar^2/(m* e^2), Ha* = e^2/(4 pi eps0 eps_xc a*), r_s = (3/(4 pi n))^(1/3)/a*;
v_xc = eps_xc - (r_s/3) eps_xc' (`lda_xc_potential`), f_xc = dv_xc/dn (`lda_xc_kernel`, unchanged); both from
`quantum_film._eps_xc_terms`, so the ground state and the optical response use one functional and one
implementation. **Convention and its ambiguity:** which permittivity screens the exchange interaction in a
polar host is not fixed by the LDA. The static value (default) includes the lattice polarization, which
follows the electrons on the phonon time scale and is the usual ground-state choice (Ando, Fowler and Stern
1982 for inversion layers); the high-frequency value screens with the electrons only (the response
module's default eps_xc = eps_inf). Measured on the 6 nm generic film: eps 4.0 roughly doubles to triples the
effect (Table 2). In the oxide penetration regions the film's units are used (the density there is tiny).
To reproduce the ground state's functional in the optical response pass `QuantumFilmResponse(..., xc=solver.xc,
eps_xc=solver.xc_eps_r or solver.eps_static)`.

**Bulk calibration.** The potential added is V_xc(n(z)) - V_xc(n_bg). A uniform gas at n_bg has a constant
xc shift that only renormalizes the band edge of the flat-band bulk; E_F is measured from that renormalized
edge, so subtracting the constant keeps the model's flat-band bulk density at E_F = sp_bulk_fermi_level_J
equal to n_bg (and the measured film work function in V_wf already contains it). Shown: a 30 nm film at
0 V with LDA has centre n/n_bg - 1 = +1.47e-4 (no xc: +1.36e-4, the O(h^2) sub-band error at h = 0.05 nm),
centre potential -1.03e-4 V either way; without the subtraction the band would sit V_xc(n_bg) = -0.1136 eV
lower and the flat-band density would be n_sep(E_F + 0.1136 eV) = 1.33 n_bg.

**Newton coupling.** U = -q phi + U_band + V_xc(n). In the Trellakis predictor the local band shift s(z)
is a second unknown: n~ = sum |psi_i|^2 n_s(E_i + s), s = -q(phi - phi_k) + V_xc(n~) - V_xc(n_k).
Linearizing, ds (1 + f_xc dn/dphi / q) = -r_2 - q dphi; eliminating ds per node leaves the tridiagonal
Poisson Newton with dn/dphi -> dn/dphi / (1 + f_xc dn/dphi / q) and right-hand side -R + (that) r_2, so the
inner iteration stays quadratic. The xc density is under-relaxed with phi; convergence also requires
max|dV_xc|/q < tol. Measured (6 nm, +-0.6 V faces, tol 1e-11 V): 10 Schrodinger solves without xc, 13 with
(two more outer iterations plus the initial xc fill), 13 when dV_xc/dn is dropped from the Newton; 25 inner Newton
iterations in total, 45 without the derivative (same fixed point to 1e-9 V). The inner tail is quadratic: every
inner step with 1e-7 < d_k < 1e-2 has d_(k+1) <= 10 d_k^2 + 1e-12, d_k the successive max density change / n_bg
(worst ratio 0.37). The outer counts are a property of the film's nonlinearity and are not gated; the test gates
the quadratic tail, its negative controls and the inner-iteration cost (Validation). The dual-gate outer iteration
counts are nearly unchanged by xc (a fresh solver per bias, anchor
included: 4 / 7 / 7 / 9 Newton steps at 0 / +2 / -2 / (2, -2) V without xc, 4 / 7 / 8 / 9 with).

Scope of the functional: the LDA is that of the spin-unpolarized single-valley gas, so xc with g_s != 2 or g_v != 1
is refused (ValueError naming g_s / g_v): for g = g_s g_v equally populated species exchange is (2/g)^(1/3) of the
unpolarized value (2^(-1/3) at g_v = 2) and the correlation is a different function
(`test_xc_refuses_a_band_the_lda_functional_does_not_describe`).

Barrier height convention with xc and a finite barrier: potentials are measured from the film's renormalized band
edge (bare edge + V_xc(n_bg)), so in the oxide (n -> 0) the Hamiltonian carries height_eV - V_xc(n_bg)/q, +114 meV on
the 6 nm 3e26 film (LDA, eps 9; +80 meV at 1e26 m^-3). That is the band-gap renormalization of the degenerate film,
correct when height_eV is the offset of the band edges without the film's gas (tabulated offsets, Anderson's rule
with the undoped film's affinity); removing it would lose the renormalization. A barrier measured relative to the
degenerate film's own band edge already contains it and must be passed as H_measured + V_xc(n_bg)/q, else it is
counted twice (module docstring; `test_xc_barrier_height_convention_adds_the_bulk_shift_in_the_oxide`: the far-wall
potential energy is q height - V_xc(n_bg) to 1e-12 relative, and the converted height puts the wall at H_measured).

## Part 3: interface traps

`GateStack(traps=physics_traps.FilmInterfaceTraps(...))`: the classical path's spec, reused by import, with
its closed-form charge `sheet_charge_C_m2`. **Which potential the traps see:** the electrostatic potential
of the interface plane, phi_s. eta = (E_F - E_c,s)/kT = (E_F_J + q phi_s)/kT, trap energies measured from the
film's conduction-band edge at the interface (the flat-band bulk edge E_F_J refers to, moved rigidly by
-q phi_s; the oxide band offset and the local V_xc do not move the trap levels). With hard walls phi_s is the
face potential (the outer unknown): Q_it(phi_s) is added to that face's interface charge in the Gauss
residual and dQ_it/dphi_s enters the outer Jacobian exactly (the film part stays a forward difference, the
trap part is subtracted from it and added analytically). With a finite barrier the interface plane is an
interior node: Q_it(phi_node) is an inner-Newton sheet source with its exact derivative.
`trap_charge_and_derivative(spec, phi_s, E_F_J, T)` returns (Q_it, dQ_it/dphi_s); the derivative is the exact
derivative of the spec's closed form (V_t [s(eta - a/V_t) - s(eta - b/V_t)] per band piece, s(1 - s) per level,
times q/kT). Empty specs (D_it = 0, no levels) are dropped, so they are bit-identical to no traps in every
mode.

## Public API

```python
from dynameta.carriers.sp_dual_gate import DualGateSchrodingerPoisson, GateStack, OxideBarrier
from dynameta.carriers.physics_traps import FilmInterfaceTraps
from dynameta.optics.quantum_film import QuantumFilm, QuantumFilmResponse
from dynameta.constants import M_E

traps = FilmInterfaceTraps(dit_eV_m2=1e17, e_lo_eV=-0.46, e_hi_eV=1.54, neutral_level_eV=0.54)
bot = GateStack(((1e-9, 3.9), (6e-9, 22.0)), work_function_offset_V=0.3,
                barrier=OxideBarrier((3.0, 1.6), (0.4 * M_E, 0.2 * M_E)), traps=traps)   # per-layer barrier
top = GateStack((8e-9, 20.0), barrier=OxideBarrier(2.5, 0.3 * M_E, penetration_m=3e-9), traps=traps)
s = DualGateSchrodingerPoisson(t_film_m=6e-9, bottom=bot, top=top, n_bg_m3=3e26, m_eff_kg=0.30 * M_E,
                               eps_static=9.0, nz=481, xc="lda")          # xc_eps_r=None -> eps_static
sol = s.solve_voltages(1.0, -1.0)
sol.n_m3, sol.z_m                       # in-film density on [0, t] (face nodes now nonzero)
sol.z_ext_m, sol.n_ext_m3, sol.phi_ext_V, sol.U_ext_J   # whole Schrodinger-Poisson domain
sol.oxide_electron_charge_bottom_C_m2, sol.trap_charge_top_C_m2, sol.phi_match_top_V
sol.sheet_excess_m2, sol.sheet_excess_total_m2      # film only / film + oxide electrons
s.penetration_m                                     # (bottom, top) depth actually used [m]
film = QuantumFilm.from_dual_gate(s, sol)           # same states: extended domain, V_xc, cell masses
resp = QuantumFilmResponse(film, eps_inf=4.0, gamma_rad_s=1.2e14, xc="lda", eps_xc=9.0)
```

New `DualGateSolution` fields (defaults = no option): `trap_charge_*`, `oxide_electron_charge_*`,
`phi_match_*`, `z_ext_m`, `phi_ext_V`, `n_ext_m3`, `U_ext_J`, `xc_potential_ext_J`, `inv_mass_ext_per_kg`,
`tail_density_ratio`; property `sheet_excess_total_m2`; `neutrality_residual_C_m2` now also sums the trap and
oxide charges (zero when no option is active). In barrier mode `face_flux_*` and `gauss_residual_*` refer
to the matching planes and `phi_bottom_V` / `phi_top_V` to the interface planes. CarrierField extras (option
mode only): `xc`, `barrier_penetration_m`, `trap_charge_*`, `oxide_electron_sheet_*_m2`,
`sheet_excess_total_m2`, `density_reporting`, `z_ext_m`, `electron_density_ext_m3`, `potential_ext_V`.

Cache: one LRU per option set (key = repr of (bottom, top, xc, xc_eps_r)); changing `s.xc` or a GateStack on
an existing solver rebuilds the derived grids and uses its own cache, switching back reuses the old entries.

## What optical consumers must do about charge in the oxide

With finite barriers part of the free electron charge lies outside the film layer, in the first nm of each
oxide (Table 1 'ox': 0.05-0.8 % of the film's electrons per side at +-2 V for 2.5-3.5 eV; up to 1.7 % at
1.5 eV). The CarrierField region "semi" carries only the IN-FILM density on [0, t] (bridge, RCWA, PMM, FEM
consumers that map n -> eps on the film layer therefore miss the oxide part); the full profile is in the
extras / `n_ext_m3`. Options, in order of fidelity:
1. Self-consistent response (`optics.quantum_film`): `QuantumFilm.from_dual_gate` now builds on the extended
   domain, so the response element spans [-d_b, t + d_t] and contains all the free charge with the exact
   ground-state states. The optical stack must then SHORTEN the adjacent oxide layers by d_b and d_t
   (`s.penetration_m`) so no thickness is counted twice. Caveat: the response uses one background eps_inf over
   the whole element, so inside the penetration regions the film's eps_inf replaces the oxide's; the error is
   first order in d (eps_inf,ox - eps_inf). Keep d short for optics: pass an explicit `penetration_m` of a
   few decay lengths rather than the round-off
   default (4-6 nm): 2-3 nm for 2.5-3.5 eV leaves a density tail of 8e-10..2e-11 at 2 nm and 1e-12..4e-15
   at 3 nm (0.3 m_e, worst of 0 / +-2 V; the solver's AdvisoryWarning fires above 1e-6). The f-sum diagnostic of the response assumes one z mass and is approximate by the
   oxide fraction times (m*/m_ox - 1).
2. Local (Drude) consumers: either add a thin oxide sub-layer carrying the oxide electron density (from
   `n_ext_m3` on the penetration nodes) with the oxide's background, or, when 'ox' is below the required
   accuracy, use the in-film density and note the missing fraction (`oxide_electron_sheet_*_m2` /
   in-film sheet).
3. Never renormalize the in-film density to the total: the oxide electrons sit at a different depth.

(the dead layer) remains in any film width; the comparison therefore (a) checks the exact statement that the

1 + (C_s + C_it)/C_ox. In accumulation delta V is ~0.06 V (hard-wall dead layer, a real quantum effect), so the

validated the DEVSIM classical film with the same spec against the same first-integral relation (its agreement
figure is not recorded here), so the in-test first integral stands for the classical path
(no DEVSIM in this fast test).

## Deviations, requests, not done

  `sp_dual_gate.trap_charge_and_derivative` both call it.

  `__all__`).
- `QuantumFilm.from_dual_gate` changed beyond an accessor in one respect: `QuantumFilm` gained the optional
  `inv_mass_cell_per_kg` field (needed for the states to equal the ground state's) and the real-space route
  uses it; the response's background eps_inf, Drude weights (film in-plane mass) and the f-sum diagnostic
  stay single-material (see the optical-consumer section).
- In-plane dispersion: the sub-band DOS uses the film mass (and Kane alpha) for every state, including the
  part of a state in the oxide (the in-plane mass of a penetrating state is a weighted average; first-order
  correction ~ ox fraction x (m_ox/m* - 1), below 1 % here).
- No tunnelling current: in the tunnelling regime the solver warns; it does not model the leak to the gate.
- The xc functional is evaluated in the film's effective units also inside the oxide penetration regions.
- Validation script not added to `validation/run_all.py`'s SMOKE list (file not owned; it is solver-free and
  ~45 s).
- No ci.yml entry: the new test file needs no solver stack (`tests/test_ci_solver_coverage.py` passes).
- Bitwise identity confirmed on this machine only (same-tree A/B is machine-independent; the before/after
  digests are not a CI gate).
