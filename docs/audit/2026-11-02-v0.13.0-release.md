# DynaMeta v0.13.0 -- release note (2026-11-02)

Branch `feat/bridge-5.50-p3`, on top of v0.12.0 (main `7996f99`). Three things in one release:

- the lumenairy bridge, verified on and expanded to lumenairy 5.50;
- every open P3 of the v0.9.0 audit (`docs/audit/2026-07-25-v0.9.0-exhaustive-audit.md`);
- every still-open item of the 2026-07-17 audit (`docs/audit/2026-07-17-exhaustive-audit.md`).

Each item is tagged in its ledger:

- v0.9.0 audit: `[FIXED wave-6]` / `[REFUTED ...]` / `[NO-CHANGE ...]` / `[DEFERRED ...]`;
- 2026-07-17 audit: `wave-7 (2026-11-02)`.

The per-topic notes listed at the end hold the measurements.

**Read section 1 before upgrading.** Several defaults and results change on purpose.

## 2. New refusals (loud errors instead of silent wrong answers)

- **`Stack.features` (vias, T-stems).** Every backend that does not implement them refuses through
  `dynameta.geometry.guards` (`UnsupportedGeometryError`, a NotImplementedError). The affected
  backends are TMM, the RCWA / 1-D PMM / PMM2D / Berreman / EMT bridges, the FDTD seam, and both
  DEVSIM builders. Before, each of them returned the via-free result bit for bit.
- **`Inclusion.taper`** (new; see section 3). Refused everywhere except the PMM2D pure engine's
  single-rectangle case.
- **lumenairy feature floors.** Each bridge path that needs a newer lumenairy raises
  `LumenairyFeatureUnavailable` ("needs lumenairy >= X (installed Y)"):
  - RCWA analytic shapes: 5.31 (below it, overlapping shapes were silently summed);
  - PMM2D pure tensor eps: 5.43;
  - PMM2D per-layer grids, walls and tapers: 5.45;
  - BOR SEM: 5.46;
  - PMM2D curved shapes: 5.50.
- **Other refusals:**
  - `inclusion_model='analytic'` with `formulation='li'/'fff'`: analytic layers are Laurent-only.
  - Fiber amps: an Er band and a Yb band with different `m_modes` (it silently halved the Yb ASE
    PSD).
  - Gummel on a bipolar device; use Newton (C-15).
  - `noise_figure` with `alpha_i > 0` but no `Gamma_g`: it returned the lossless NF.
  - `amplify_coherent` with `gvd_segments > 1` together with `langevin` or `state0`, which were
    silently dropped.
  - `HotCarrierParams` with `T_l_K < T_e0_K` while `G_e_l > 0`.
  - `hydro_fem` `*_nm` lengths below 1 pm.
  - `*_design` angles outside the radian range.
  - `stack_axis='x'` in the 2-D lift.
  - `IdentityLift.apply` on 3-D arrays.
  - A heterojunction without electron affinities.

## 3. New features

- **lumenairy bridge on 5.50:**
  - ceiling raised to 5.50; the theta = 0 PMM angle gradient is confirmed fixed upstream;
  - PMM2D pure engine: tensor (LC) layers, Circle / Ellipse via `shapes=`, non-commensurate
    rectangles (`pure_grid`), transmission `t`, periodic wrap-around, and tapered rectangular pillars
    (`taper_slices`, `taper_rule`);
  - RCWA: analytic shapes (`inclusion_model`); a uniform tensor background with inclusions painted
    over it (it used to drop the inclusions); laterally uniform tensor stacks on a single order (17-25 s
    -> 4-11 ms per solve);
  - BOR: SEM basis (`basis='sem'`, `degree`, `elements_per_segment`);
  - reverse translation of analytic shapes and uniform tensors;
  - 1-D PMM wrap-around;
  - `make_bor_spec_solver` (the old `make_lumenairy_bor_solver` is a deprecated alias).
- **`Inclusion.taper` / `Taper`:** a sidewall taper about the shape's own centre, widest at the top.
  Slant is refused. `Taper.from_sidewall_angle` builds one from an angle.
- **SOA metrics (A-23):** `transfer_derivatives_fd` and `transfer=` on `sndr_vs_drive` /
  `optimal_drive_power` / `sfdr_dB` (finite differences with a Richardson step and an error
  estimate). The sampled path reports its own error and raises `TransferFitWarning`.
- **Fiber transient marches:**
  - `z_refine` on both marches;
  - `_OscillationMonitor`: ringing marches are flagged, and `ase_mode="auto"` switches to the
    self-consistent step;
  - `TransientResult.assert_valid()`;
  - log-sum-exp overflow guard.
- **FDTD:** the 3-D JAX kernel gains Lorentz, chi2, Raman and gain terms (matching numpy to 3e-15;
  `jax.grad` checked against finite differences).
- **`dynameta.warning_types`:** `UnreliableResultWarning` (a RuntimeWarning subclass),
  `AdvisoryWarning` (a UserWarning subclass) and `DynaMetaDeprecationWarning`, used at about 80 sites.
  Existing filters keep working.
- **`dynameta.constants`:** `Z0` and `T_REF`, now the single sources.

## 4. API changes and deprecations

Every rename keeps an alias that emits a DeprecationWarning:

- `resonance.Layer` -> `LayerSpec`;
- `nonlocal_tmm.Layer` -> `NonlocalLayer`;
- `invert_kirchhoff(theta_W_m=)` -> `theta_W_per_m=`;
- `propagate_gnlse` / `cpa_chain` / `dispersion_length` / `nonlinear_length` / `soliton_order`:
  `beta2_s2_m` / `beta3_s3_m` / `gamma_W_m` -> `beta2_s2_per_m` / `beta3_s3_per_m` /
  `gamma_per_W_m`;
- `make_lumenairy_bor_solver` -> `make_bor_spec_solver`;
- `ThermalLayerTwoTemp(k_electron=None)` now warns.

Other changes:

- `build_thermal_forms` returns 8 values; the new one is `T_lift` (X-17).
- `photon_density` returns a Python float for scalar input.
- `sfg_two_step` returns `propagating`.
- `QDGainParams` gains hole-side fields.
- `Stacked3DSpec` gains `chi_semi_eV` and `band_alignment()`.
- `solve_fdtd_1d` gains `drude_n_m3`; `drude_of_t` accepts a `DrudeOptical`.

Removed:

- the "envelope" oblique FEM route (F-16; reachable only by editing a module constant, and wrong at
  oblique incidence);
- 12 unread `fdtd_nd` aliases;
- 4 dead private helpers.

## 5. Correctness fixes with no API change (selection)

- **Raster and inclusion handling:** one periodic raster predicate (`rasterize.inclusion_mask`) for
  RCWA, FDTD and PMM2D.
- **Density-gradient contact current (S1-5):** conservation error 2.95e-2 -> 4.4e-16.
- **Fermi integrals:**
  - `_fd1` lost precision for x << 0 and was exactly 0 below -36.7; now accurate to 1.3e-15
    (S1-18);
  - the Freedericksz onset threshold was 0.742x the true value (S1-13).
- **Graphene sigma:** was NaN below ~6.5 K at 1.55 um (S4-22).
- **Interface naming:** sub-nm interface planes shared one name, so a sheet BC was applied twice
  (F-19).
- **SFG / DFG:** the evanescent probe was ~sin^2(theta3) too large (F-20).
- **TMM:** `'x'` at oblique incidence was silently s-pol (Q-24).
- **Materials:** the stable polymorph was sorted last in the materials-DB query (Q-25).
- **GMRes tolerance (v0.12.0):** see `2026-11-02-fem-speed-and-pml.md`.
