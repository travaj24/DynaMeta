Notes for P11:
1. Request `fermi_ref_param` ONLY for an equilibrium region that has an edge electrode with
   `pin_potential=False`. With the parameter at 0 the solution equals the default closure to round-off,
   not bit for bit (DEVSIM canonicalises the closure's expression tree; the longer eta subtree reorders a
   few products: MEASURED 1 ulp, 2.4e-16 relative in n, ~1e-18 V in the solved potential). Regions without
   an edge electrode, and `pin_potential=True`, must keep `fermi_ref_param=None` to stay bit-identical.
2. `install_film_interface_traps` and the routed fixed charge read the region kind from the equation
   registry and the region's eta string from `setup_semiconductor_region`, so they must run after the
   region physics and `setup_interface` (the builder's `_install_interface_traps` already runs there) and
   they automatically follow `fermi_ref_param` and the Anderson-frame `Phi_c0`.
3. The C5 guard will warn (filterwarnings = error) wherever a density-dependent DOS mass reaches a
   builder: `validation/_reference_device.ito_dos_mass` varies by 78 % over [0.1, 10] n_bg (MEASURED), and
   `examples/lumenairy_gated_grating.py` has the same function. Tests that build that device through a
   builder (tests/test_gated_builder.py, test_extended_precision*.py, test_devsim_junction_band.py,
   test_devsim_noise_method.py, _noise_method_child.py, _trap_noise_child.py) need a `pytest.warns` or an
   explicit filter for that one message once P11 wires the guard.
4. Two edge electrodes at different voltages on one equilibrium region must raise (plan C2); P5 has no
   state for it, the check belongs in the builder.
5. 3-D: the primitives are dimension-agnostic (`interface_node_area` handles 3-D triangles); whether
   `Stacked3DSpec` accepts them is P11's decision.

## Derivations (brief)

- **Fermi-level reference.** eta = (E_F - E_c)/kT, E_c = q(Phi_c0 - psi) (the closure's frame), and an
  equilibrium contact at V sets E_F = -qV everywhere in the region: eta = (psi - V - Phi_c0)/V_t. Hence the
  solution at (V, every Dirichlet potential + V) is the V = 0 solution shifted by V, exactly.
- **Sign of a charge term.** DEVSIM's Poisson row is sum(outward flux eps(psi_0 - psi_1)/L) + NodeVolume *
  PotentialNodeCharge = 0; the box form of Gauss's law makes PotentialNodeCharge = -rho. A positive charge
  density c [units of q] enters as `- ElectronCharge * c`. A sheet Q is c = w Q/q with w =
  A_node/NodeVolume, so the interface node's residual gains exactly -A_node Q. Either side of the interface
  may carry it (the `continuous` interface equation sums the two rows). Checked against Gauss on a
  two-dielectric stack to 1e-12 and by the -Q/C_ox shift.
- **Work function.** The vacuum level is continuous, E_vac = W_s - q psi with W_s = chi + (E_c - E_F) at
  psi = 0; at the gate E_vac = -qV + phi_m, so psi_gate = V - (phi_m - W_s)/q. The relation does not
  involve the semiconductor's Fermi level, so it is unchanged with a Fermi-level reference.
- **Interface traps (equilibrium film).** f(E) = s(eta - E/V_t) with s the logistic function; with S =
  ln(1 + e^x): int_a^b f dE = V_t [S(eta - a/V_t) - S(eta - b/V_t)], int_a^b (1 - f) dE = V_t [S(b/V_t -
  eta) - S(a/V_t - eta)]; acceptor-like states carry -q f, donor-like +q (1 - f). d eta/dpsi = 1/V_t gives
  dQ/dpsi = -q D [f(a) - f(b)] per band piece and -q N f(1 - f)/V_t per level, i.e. C_it = q^2 D_it inside
  the band and d psi_s/dV_G = C_ox/(C_ox + C_s + C_it). S and s are written overflow-free (DEVSIM traps exp
  overflow even in the unselected branch of `ifelse`, MEASURED).
- **C5 guard.** The callable is probed at 0.1, 0.2, 0.5, 1, 2, 5, 10 n_bg with one scalar call each.

## Deviations from the plan

1. `fermi_ref_param` at 0 is not bit-identical to the default closure (see note 1 above); the plan asked for
   "to the solver tolerance" for the shift, which holds.
2. Work-function equivalence is bit-identical only when the offset is added to the bias value; the
   contact-string route agrees to < 1e-12 V. P11 should use the bias route.
3. `Electrode.work_function_eV` must be > 0 (plan: finite) and is refused on edge electrodes;
   `pin_potential=True` is refused on non-edge electrodes (plan: "only meaningful").
4. The fixed-charge routing applies to any `InterfaceTraps` without trap levels, whatever its
   `recombination` flag (without levels there is no recombination to lose).
5. `.github/workflows/ci.yml` not edited (owned by P15): add `tests/test_equilibrium_charges.py` to the
   solvers-devsim list.
