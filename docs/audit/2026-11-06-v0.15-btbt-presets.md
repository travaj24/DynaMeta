## What changed (`dynameta/carriers/tunneling.py`)

* **`BTBTParams` gains five keyword fields with defaults, appended after `P`** (backward compatible:
  `BTBTParams(A, B, P)` and every v0.14 call are unchanged; `SILICON_HURKX` keeps its bits):
  * physics (compared, hashed): `T_K: Optional[float] = None` -- the temperature A, B are quoted at (None =
    T_REF); `scale_B_with_gap: bool = False` -- the opt-in E_g^(3/2) scaling of B;
  * provenance (`compare=False`, no physics): `source: str = ""`, `process: None | "direct" |
    "phonon_assisted"`, `verification: None | "primary" | "secondary" | "computed"`;
  * `from_cgs(A, B, P, **fields)` passes the keyword fields through; property `quoted_T_K`.
* **`kane_direct_params(Eg_eV, m_r_over_m0, g=2.0, *, source, verification="computed")`** -- THE function for
  Kane direct-process sets (Sentaurus UG N-2017.09 Eqs. 495-496, read; Kane's g = 2 form). A computed preset
  is a call of it.
* **Shipped sets** (decisions 18, 19):

  | set | A (printed) | B | P | verification | source |
  |---|---|---|---|---|---|
  | `SILICON_HURKX` (unchanged) | 4e14 cm^-1/2 V^-5/2 s^-1 | 19 MV/cm | 2.5 | secondary | Hurkx 1992 via Sentaurus UG Table 90 |
  | `SILICON_KAO_DIRECT` | 1.35e20 cm^-3 s^-1 | 101 MV/cm | 2 | secondary | Kao 2012 Table III via Jiao 2013 Table 1 |
  | `SILICON_KAO_INDIRECT` | 3.29e15 | 23.8 MV/cm | 2.5 | secondary | same |
  | `GERMANIUM_KAO_DIRECT` | 1.46e20 | 6.04 MV/cm | 2 | secondary | same; A as printed (decision 19) |
  | `GERMANIUM_KAO_INDIRECT` | 1.67e15 | 6.55 MV/cm | 2.5 | secondary | same |
  | `GERMANIUM_KAO` | the tuple (direct, indirect) | | | | Kao: Ge needs both |
  | `IN053GA047AS_KANE` | computed: A_SI = 1.7363e22 m^-3 s^-1 (V/m)^-2 (= 1.736e20 cm^-3 s^-1) | 5.518 MV/cm | 2 | computed | `kane_direct_params(0.73726 eV, 0.023463)` |

  Not shipped: vendor defaults (Sentaurus E2, Sentaurus Ge 9.1e16 / 4.9 MV/cm), Atlas BBT.STD, any InGaAs fit.
* **Several processes per region.** `btbt=` (`setup_btbt`, `setup_bipolar_region`, `TransportModel.btbt`,
  `Stacked3DSpec.btbt`) accepts one set or a non-empty tuple. One set: exactly the v0.14 names (term `btbt`,
  `BTBT_U` / `BTBT_U0`, `BTBT_U1`). A tuple: term `btbt_<k>`, models `BTBT_U_<k>` (1-D) / `BTBT_U0_<k>`,
  `BTBT_U1_<k>` (2-D/3-D), one shared `BTBT_Emag`; the terms sum through the one additive mechanism, each
  with its own noise pair rate. `btbt_generation_current(..., index=None)` returns the sum of the per-term
  currents, or term `index`.
* **Temperature (decision 20, opt-in).** `btbt_at_temperature(btbt, T_K, gap_ratio)` is the one scaling:
  B -> B ratio^1.5, A and P unchanged, result tagged `T_K` (sets without the flag are returned as the same
  object). `btbt_for_material(btbt, transport_model)` is the builders' hook: for each flagged set, ratio =
  `materials.band_gap_ratio(tr, T_region, T_set)` from the material's band-temperature model (the one gap
  law); without a model the set passes unscaled. The 2-D `LayeredDevsimBuilder` and
  `Stacked3DSpec.from_design` call it (one line each; `devsim_layered.py`, `devsim_3d.py`).
  `setup_btbt` warns (the v0.14 row 3.2-9 advisory, wording kept so its gate still matches) for every set
  whose quoted temperature differs from the region's V_t, names the sets' temperature, and says when a set
  is flagged but no ratio reached it.
* Docstrings: module header (sets table, units, which set for which calculation, temperature options),
  `setup_bipolar_region`, `TransportModel.btbt`, `Stacked3DSpec.btbt`, `bipolar_options` item 4,
  `band_gap_ratio`.

### Which option for which calculation

| need | use |
|---|---|
| Si junction, local model | `SILICON_HURKX` (the shipped default fit) or `SILICON_KAO_INDIRECT` (Kao's theoretical [100] set). The Si direct set is the Gamma process, negligible below ~1e9 V/m. |
| Ge | `GERMANIUM_KAO` (the tuple). Direct dominates at every practical field (gated, below), but the indirect share is visible (2e-3 of the current at -1 V in the P5 fixture). |
| In0.53Ga0.47As | `IN053GA047AS_KANE`, a Kane estimate (no traceable calibrated local set exists). |
| a direct material with cited E_g, masses | `kane_direct_params(...)`, label it computed. |
| device at T != 300 K | `dataclasses.replace(set, scale_B_with_gap=True)` + `TransportModel.band_temperature`; or a set fitted at T with `T_K=T`. |

## The Kao primary: what was read

Not readable. Attempts (2026-11-06): IEEE Xplore (OpenAlex: `oa_status` closed, no repository full text);
the imec repository record lists `23106.pdf` with embargo 9999-12-31, and its bitstream returns HTTP 401;
ResearchGate and Semantic Scholar return 403; Unpaywall was not queried (it needs a personal e-mail). Two
secondaries were checked and do NOT reprint Table III: US 11,233,131 (cites Kao for its Kane parameters but
prints its own 19 MV/cm and 4.55e16 / 4.9 MV/cm sets) and Micromachines 10, 77 (PMC6412961, "calibrated by
referring [30]", no numbers in the text). **What the sets are re-typed from:** Jiao et al., J. Semicond. 34,
092002 (2013), Table 1 (open access), whose caption says the "Direct BTBT" and "Indirect BTBT" columns are
"the results calculated in Ref. [14]" (= Kao 2012) for tunnelling along [100]; the page image
(`lit_btbt/jos2013/T1.jpg`) was read, and the extracted text agrees digit for digit. Hence
`verification="secondary"` on all four Kao sets and the strict xfail below.

**Ge-direct consistency (decision 19), INFERRED from the printed numbers.** With E_g(Gamma) = 0.80 eV and
m_r = 0.022 (the plan's inference, not Kao's stated inputs) the Kane formula gives B = 6.039 MV/cm (match)
and A = 1.614e20 cm^-3 s^-1, +10.5 % over the printed 1.46e20. No (E_g, m_r) with g = 2 reproduces both
printed numbers except E_g = 0.841 eV, m_r = 0.0189; the Si-direct pair implies E_g = 3.58 eV, m_r = 0.069.
Kao may use another degeneracy factor or a non-parabolic m_r; only the primary can tell. Shipped as printed.

## Findings (reported; outside the gates or the plan's claims corrected)

* **Plan P6 claim corrected.** "The direct share grows with field for Ge" is false for Kao's numbers:
  direct/indirect = (A_d/A_i) F^-0.5 exp((B_i - B_d)/F) = 8.7e5 F^-0.5 exp(5.1e7/F) DEcreases with F but
  stays > 1 up to ~7.6e11 V/m. That is Kao's own abstract statement ("direct tunneling always dominates
  over indirect tunneling in Ge"), so it doubles as an independent check of the re-typed digits.
* **The 1-D Zener analytic estimate does not resolve the Si Kao sets.** The rate decays over
  1/k = (V_bi + V_r)/B from the peak field, 0.1-0.5 nm for B = 2.4-10 GV/m, comparable to the mesh. MEASURED
  (n_i = 1e19, so delta_D ~ 0): Si direct at 1e26 m^-3, 0.3 V: +7.9 / +15.1 / +17.1 % at 0.2 / 0.1 / 0.05
  nm; Si indirect at 1e25: +1.8 / +2.7 / +1.5 % (non-monotone; with n_i = 1e16, +0.05 / +0.79 / +0.21 %).
  The discrete peak field matches the analytic Emax to 2-3e-5, so the gap is in the resolution of a
  sub-nm rate peak (and the D profile, which changes on Vt/E ~ 0.06 nm at these fields), not in the units:
  the P4s frozen-state gate covers the Si sets' wiring exactly. Hurkx/Z1 (B = 1.9 GV/m at 5e18 cm^-3)
  sits at k h ~ 0.2 and is fine. Not root-caused further (a mesh study with h <= 0.02 nm is the next step
  if a Si-direct Zener gate is wanted).
* **CODATA vintage.** `dynameta.constants.M_E` is CODATA 2018 (9.1093837015e-31); scipy 1.17 ships CODATA 2022
  (9.1093837139e-31), 1.36e-8 relative higher. The Kane oracle pins the 2018 literal; with scipy's m_e the
  Kane sets move by 6.8e-9.
* **InGaAs masses are low-temperature values** (Vurgaftman's recommendation), used with the 300 K gap. A
  k.p-consistent 300 K electron mass would be ~10 % lower (INFERRED: m_e ~ E_g scaling), lowering B by ~5 %.
  Stated in the set's source.
* **Direct-process sets in indirect materials** scale with the material's FUNDAMENTAL gap ratio (the one
  band-temperature model); the Gamma gap's own temperature law is not modelled. Stated in the module.
* `docs/plans/.../P1_tunneling.md` still quotes the old InGaAs gap row (0.763 eV); not edited (plan file).

## Release-note lines

- **More BTBT parameter sets:** `SILICON_KAO_DIRECT/INDIRECT`, `GERMANIUM_KAO` (direct + indirect, both
  needed in Ge) from Kao et al., IEEE TED 59, 292 (2012) (re-typed from a reprint; the original was not

  noise source; `btbt_generation_current(index=)` reports one.

  material a `band_temperature` model; or tag a set fitted at T with `T_K`. Without either, the v0.14
  warning stays. Nothing changes by default.
