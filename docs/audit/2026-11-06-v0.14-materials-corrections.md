# v0.14.0 materials corrections: del Alamo BGN basis, Sb level, BGN n_i notes, ionization units guard

**Date:** 2026-11-06. **Branch:** `wip/v014_p2fix` (cut from `feat/devsim-2.11-v0.14` at 189c648).
**Scope:** consolidated plan `docs/plans/2026-11-04-devsim-v0.15/00_consolidated_plan.md`, section 3.2,
rows 3.2-4, 3.2-5, 3.2-6 and 3.2-11; details in `P2_materials_api.md` (finding 0.2, item 1.3 E,
item 4, decisions D4 and D7). User decisions: 1 = "all", 31 = no default alpha, guard and advisory now,
Altermatt 2006 later.

All code changes are in `dynameta/carriers/bipolar_options.py`. Nothing here was released (v0.14 is
untagged), and everything is opt-in, so only callers who already set `BipolarOptions(bgn=...)` or
`BipolarOptions(ionization=...)` see a change.

## What changed

### 3.2-4: del Alamo BGN is an n-type fit in N_D

*Wrong:* `BGN_SI_DEL_ALAMO_1985` applied `18.7 meV ln(N/7e17)` to `N = N_D + N_A` and cited
Solid-State Electron. 28, 47 (1985). The fit is del Alamo & Swanson, IEEE TED ED-34, 1580 (1987),
Eq. (11), and del Alamo, Swirhun & Swanson, IEDM 1985, p. 290, Eq. (7). Both were read in the primary
text (scratchpad `lit_bgn/RJ-20.txt`, `RC-14.txt`). The fit is made only for phosphorus-doped n-type
Si, in N_D.

*Done:*
- `BGNModel` has a new field `doping_basis`: `"total"` (N_D + N_A), `"donors"` or `"acceptors"`.
  None (the default) means the kind's own basis: `"total"` for `slotboom`, and `"donors"` for
  `del_alamo`, so a user-built del Alamo model is also corrected.
- `equilibrium_fields` evaluates the fit in `bgn.basis_density_m3(N_D, N_A)`. For `"total"` the
  arithmetic is the old `N_D + N_A`, so Slotboom and Klaassen results are bitwise unchanged.
- The citation is corrected.
- **Warn, not refuse** (P2 1.3 E: the legacy presets stay unpaired and are not refused).
  `install_option_fields` emits one `UnreliableResultWarning` per region in which some node has N_A > N_ref
  (7e17 cm^-3). Those are p-type or compensated nodes where the fit would be needed and has no basis.
  The pure helper `bgn_basis_advisory` builds the text.
- The warning threshold is the fit's own onset N_ref. A lightly compensated n+ node (N_A <= 7e17)
  and the p base of the R27-c diode (1e17) are silent.

### 3.2-5: Sb ionization energy

*Wrong:* Sb was 39 meV, which matches Sze & Ng but is out of date. The spectroscopic 1s(A1) binding
energy is **42.74 meV** (Ramdas & Rodriguez, Rep. Prog. Phys. 44, 1297 (1981), Table 4). I re-read
it in the scan `lit_pb_hooge/rr_p25.png`.

*Done:* `SI_DONOR_IONIZATION_EV["Sb"] = 0.04274`, with the new citation.

P and As keep Sze & Ng's 45 and 54 meV. The same table gives 45.59 and 53.76 meV, so each is less
than 1 meV away. P2 marks these rows optional, and moving P would move the R27-d freeze-out gates.
B was not changed: its spectroscopic value was not seen in the primary.

### 3.2-6: BGN reference-n_i notes (documentation only)

*Wrong:* The R27 audit note said "the commonly quoted modern pairing is n_i = 1.0e10 cm^-3". No
shipped set was fitted with 1.0e10:

| Set | Fitted n_i | Label |
|---|---|---|
| Old Slotboom | about 1.44e10 (fitted on p-type transistor bases) | inferred |
| del Alamo | about 1.36-1.45e10 | inferred |
| Klaassen | 1.0e10 or 1.08e10 | unverified |

The modern value is 9.65e9 (Altermatt et al., J. Appl. Phys. 93, 1598 (2003)). It goes with
Fermi-Dirac statistics and a real (not apparent) narrowing.

*Done:*
- The module docstring (item 2) now has a reference-n_i table and says which n_i to pass for which
  calculation.
- The preset `source` strings carry the basis, the fitted n_i and "unpaired".
- `2026-11-03-devsim-recombination-bgn-ionization.md` is corrected: the formula block, the preset
  table, and open questions 2 and 5. Each correction is marked with its date.
- A grep for "Sproul", "modern pairing" and "1.0e10" turns up no other statement of the wrong
  pairing outside the plans, which describe the correction.
- No gate moves, because the presets stay unpaired.

### 3.2-11: Pearson-Bardeen units guard, converting constructor, Mott-density warning

*Wrong:*
- **Units.** `alpha_*_eVm` is in eV*m, but the literature quotes eV*cm. An unconverted 3.1e-8 zeroes
  a 45 meV level at 3.06e12 cm^-3. The clamp at 0 then shows this as full ionization, silently.
- **No Mott transition.** The legacy single-level model freezes out above the Mott density.

*Done:*
- **Guard.** `IonizationModel.__post_init__` raises **`IonizationUnitsError`** (a `ValueError`)
  when alpha > 0, dE0 > 0 and the zero crossing (dE0/alpha)^3 < 1e17 cm^-3. The comparison is done
  in N^(1/3), so it cannot overflow. The message says "alpha looks like eV*cm; this field is eV*m =
  1e-2 x eV*cm". A genuine Pearson-Bardeen alpha (the ATLAS example) vanishes at about 1.8e18 cm^-3,
  1.3 decades above the guard.
- **Converting constructor.** `IonizationModel.pearson_bardeen(dE_D_eV, dE_A_eV, *, alpha_D_eVcm,
  alpha_A_eVcm, **kw)` takes eV*cm and converts by 1e-2.
- **No default alpha** (decision 31).
- **Shared kernel.** `IonizationModel.ionization_energies_eV` is now the one place the lowered,
  clamped energies are computed. `equilibrium_fields` calls it, and the arithmetic is unchanged.
- **Mott-density warning.** New fields `N_mott_D_m3` and `N_mott_A_m3` set the thresholds:
  - donors: 3.74e18 cm^-3 (Si:P [P]; also "about 3.7e18" in del Alamo & Swanson 1987);
  - acceptors: 4.5e18 cm^-3, Altermatt 2006's N_b for B, used as a documented proxy [U];
  - `math.inf` silences the warning.
- `install_option_fields` emits one `UnreliableResultWarning` per region in which a node above N_mott still
  has a non-zero ionization energy. The message quotes the model's worst non-ionized fraction. The
  pure helper `mott_advisory` builds the text.
- The warning is skipped where the Pearson-Bardeen lowering has already zeroed the energy, because
  the model then predicts full ionization there.

## Open questions

1. **Compensated nodes below N_ref move without a warning.** For example, 5e17/5e17 goes from
   6.67 meV to 0. The warning threshold "N_A > N_ref" was chosen so that background compensation in
   n+ regions stays quiet. A stricter rule, such as "any N_A > 0 where the old basis would have
   narrowed", would warn on every real n+ emitter.
2. **Warning category (decided 2026-11-06 by the coordinator).** Both new warnings are
   `UnreliableResultWarning`, not the `AdvisoryWarning` the plan named: by `dynameta/warning_types.py`
   a model used outside its validity range is exactly that category ("the RETURNED VALUE may be
   wrong"), while `AdvisoryWarning` is reserved for trustworthy results. It keeps `RuntimeWarning` as a
   base, so `filterwarnings('error', category=UnreliableResultWarning)` fails a sweep fast on these
   regions. Nothing in the suite filters the category specially (pyproject `filterwarnings = ["error"]`
   treats both categories alike; the only category-specific filter in library code is
   `optics/fiber_amp/dynamics.py`, unrelated). The BGN + FD double-counting note stays `AdvisoryWarning`.
3. **Mott thresholds.** The As/Sb donor thresholds use the Si:P value (conservative). The B threshold
   is Altermatt's N_b proxy [U]. Both are documented on the field.
4. **P, As and B energies** were not moved to the spectroscopic values (optional per P2, each < 1 meV;
   B unverified).

## Release-note lines

- **Bipolar BGN:** the del Alamo preset is now evaluated in N_D only, as published (IEEE TED 1987
  Eq. 11; the citation is corrected). p-type and compensated nodes no longer get a narrowing the fit
  does not support, and regions with N_A > 7e17 cm^-3 emit an `UnreliableResultWarning`. Pure n-type results are
  unchanged. `BGNModel` gains `doping_basis`.
- **Incomplete ionization:** the Sb donor level is now 42.74 meV (Ramdas & Rodriguez 1981), up from
  39 meV. A Pearson-Bardeen alpha passed in eV*cm into the eV*m field now raises
  `IonizationUnitsError`; use `IonizationModel.pearson_bardeen(..., alpha_D_eVcm=...)`. Regions doped
  above the Mott density emit an `UnreliableResultWarning`, because the single-level model freezes out
  wrongly there.
- **Docs:** the BGN presets now state the n_i they were fitted with (none used 1.0e10; the modern
  value is 9.65e9 cm^-3).
