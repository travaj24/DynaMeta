## Part 1: Q4 and N3

**Derivation.** The sub-band Hamiltonian is separable (free in-plane motion x confined z states). A field along x
accelerates every electron in-plane: the intraband Drude eps_xx. A uniform field along z cannot accelerate a confined
electron; second-order perturbation theory gives eps_zz = eps_inf + sum_{i<j} S_ij / (eps0 (w_ij^2 - w^2 - i w gamma)),
S_ij = N_ij q^2 z_ij^2 2 w_ij / hbar. The TRK rule makes the strengths of a complete set exhaust the free-carrier
response, sum_{i<j} (n_i - n_j) f_ij = sum_i n_i, so at w >> w_ij the sum already tends to -wp^2/w^2 (with the
Schrodinger mass); the v0.15.1 form added a Drude term on top of it (a double count in every regime; for an
isolated well the confined electrons have no free z motion at all). Only a population outside the sub-band set has a
Drude response; it is isotropic, so `free_density_m3` enters eps_xx and eps_zz alike (see deviations).

**N3.** `Z = psi^T diag(z - z_c) psi h`, z_c the midpoint, h the uniform spacing (raises for a non-uniform grid,
rtol 1e-6) -- the quadrature the eigenvectors are normalized with, so they are exactly orthonormal under it and the
off-diagonal dipoles do not depend on the origin. One matrix product; the pair sum is vectorized.

**f-sum diagnostic.** `last_fsum_ratio` = sum (n_i - n_j) f_ij / sum n_i with `subband_mass_kg` (default m_opt);
AdvisoryWarning outside [0.9, 1.05] in "subbands" mode (`fsum_check="off"` silences). Exact discrete identity (used
as the test oracle): for the finite-difference Hamiltonian the double commutator gives sum_j f_ij = kappa_i =
h sum_k psi_i,k psi_i,k+1, so for a complete set the ratio is sum n_i kappa_i / sum n_i (1 - O((k h)^2)).

## Part 2: the self-consistent response (`optics/quantum_film.py`)

### Formulation and approximations

- Ground state: the SchrodingerPoisson1D slab model, COMPLETE discrete basis (all N-2 interior states,
  `QuantumFilm`; `from_dual_gate` recomputes them from the converged dual-gate potential -- the dual-gate solution
  keeps only the states it needs for the density). Kane option: in-plane only, exactly as the solver (the z
  dispersion stays parabolic, so the intersubband energies do not depend on k in this separable model; a full Kane
  treatment -- energy-dependent z mass, k-dependent transition energies -- is NOT modelled).
- Electronic response at in-plane q -> 0 (q << k_F, q v_F << omega; dropped terms relative O((q/k_F)^2,
  (q v_F/omega)^2), here 4e-6 / 7e-6 at 60 deg / 1200 nm on the generic gated film): out of plane, the
  intersubband transitions with
  transition densities zeta_p = psi_i psi_j and their running integrals Xi_p, P(z) = eps0 sum_p g_p Xi_p(z)
  int Xi_p E, g_p = s_p/(w_p^2 - Omega^2) -- the nonlocal sigma_zz(z, z'); in plane, the local intraband Drude with
  Drude weight e^2 n_i/m (parabolic) or the Kane Fermi-surface average (exact sheet current; the in-plane
  distribution differs from the exact projected one only at second order in qL).
- Damping on the velocity, Omega^2 = omega (omega + i gamma): exact static limit, f-sum for every gamma, number
  conserving (orthogonal transition densities) -- what Mermin's correction restores in the Lindhard function; the
  in-plane Mermin correction is O((q v_F/omega)^2) and is dropped. One gamma for every transition.
- Self-consistent field: Hartree through Maxwell's equations (D_z = eps0 eps_inf E_z + P, D_z = -(q/omega) H_y),
  so the depolarization interaction, retardation and the dielectric environment are exact within the electromagnetic
  solution (no separately chosen Coulomb kernel; at q -> 0 it reduces to M = int Xi_p Xi_q / eps_inf, cladding-
  independent). Optional adiabatic LDA xc (exchange, or exchange + PZ81 correlation, background eps_xc = eps_inf by
  default). Collective modes from B = diag(w_p^2) + S^1/2 K S^1/2 (multisubband plasmons); the f-sum of the full
  response is exactly the bare one. M replaced by its rank-one uniform-field part reproduces IntersubbandEffect
  exactly; the difference is positive semidefinite, so (without xc) every mode moves UP from the local prediction.
- Two routes: transition-basis modes, and real-space Sternheimer (occupied states only; cost occ x N^2 per
  frequency). Cross-checked to ~1e-11.
- Not modelled: in-plane dispersion of the electronic response, band offsets / z-dependent mass in the film,
  frequency- or transition-dependent damping, spill-out through the walls (hard walls, as in the SP solve), lattice
  local fields.

### Public API

```python
from dynameta.optics.quantum_film import QuantumFilm, QuantumFilmResponse
from dynameta.optics import nonlocal_tmm as nt
from dynameta.carriers import DualGateSchrodingerPoisson, GateStack

s = DualGateSchrodingerPoisson(t_film_m=6e-9, bottom=GateStack((6e-9, 20.0)), top=GateStack((6e-9, 20.0)),
                               n_bg_m3=3e26, m_eff_kg=0.30 * M_E, eps_static=9.0, nz=481)
film = QuantumFilm.from_dual_gate(s, s.solve_voltages(2.0, 2.0))      # complete sub-band set
resp = QuantumFilmResponse(film, eps_inf=4.0, gamma_rad_s=1.2e14)    # xc="none" | "x" | "lda"
w = 2 * np.pi * C_LIGHT / 1200e-9
res = resp.stack_rt(w, [nt.DielectricLayer(2.00**2, 6e-9)], [nt.DielectricLayer(2.00**2, 6e-9)],
                    n_sub=1.45, theta_rad=np.deg2rad(60))             # exact element (model="rpa")
res.r, res.A
T = resp.transfer_matrix(w, k_par)                  # 2x2, nonlocal_tmm basis/orientation (superstrate_face="top")
eps_xx, eps_zz, L = resp.effective_layer(w)         # uniaxial thin layer for RCWA / PMM / FEM
resp.alpha_perp(w), resp.alpha_par(w)               # sheet response lengths [m]
resp.sigma_zz_kernel(w), resp.response_kernel(w), resp.induced_charge(w)
resp.modes(), resp.fsum(), resp.validity(w, k_par)
```

Also `film_transfer_matrix(omega, k_par, h, eps_xx_nodes, eps_inf, R)` (any local/nonlocal kernel R),
`film_stack_rt`, `uniaxial_layer_matrix`, `lda_xc_kernel`.

Thin-film boundary conditions: to first order in L the film is the uniaxial layer eps_xx,eq = eps_inf + alpha_par/L,
1/eps_zz,eq = (1 - alpha_perp/L)/eps_inf, alpha_par = i sigma_s/(omega eps0), alpha_perp = p_s/D_z (response lengths,
the film analogue of Feibelman's d-parameters); the equivalent zero-thickness sheet in a host eps_h:
[H_y] = i omega eps0 (alpha_par + (eps_inf - eps_h) L) E_x, [E_x] = i (q/eps0)((L - alpha_perp)/eps_inf - L/eps_h) D_z.
Measured error of the first-order layer vs the exact element (item-4 fixture, re-measured on the generic gated film):
1.3e-7 to 9.2e-7 in r for symmetric films, 3.7e-5 to 7.0e-5 for one-sided gating (an asymmetric film's response
position along z enters at the next order).
For laterally structured solvers the equivalent layer needs q_x L << 1, q_x << k_F, q_x v_F << omega for every
lateral order that carries field, and a laterally uniform ground state (else per-column films) -- `validity()`.

## Deviations from the plan

1. `z_free_density_m3` -> `free_density_m3`, added to eps_xx AND eps_zz: a population outside the sub-band set
   moves freely along every axis.
2. `thickness_m` (new) and the default Leff. A Dirichlet-slab SubbandResult lives on the interior nodes, so the film
   is z[-1] - z[0] + 2h thick; the v0.15.1 Leff = z[-1] - z[0] spread the sheet response over 2h too little (2h/L:
   1.0 % at 201 nodes on 6 nm) and converged only as O(h). The default (z_response='subbands') is now the
   wall-to-wall thickness read from the grid convention -- + h at each end node where psi does not vanish (an end node
   with every |psi| <= 1e-10 max|psi| is itself the wall) -- so eps converges as O(h^2): successive differences of
   eps_zz - eps_inf at 101/201/401/801 nodes shrink by 3.93 / 3.98 (old default 1.64 / 1.83;

   'drude_plus_subbands' form keeps z[-1] - z[0]. Measured effect: 6 nm film at 241 nodes |eps_zz - eps_inf| 1.16
   (1.17 before); wide-slab |eps_zz - eps_xx| 0.0509 / 0.0257 / 0.0133 at 10 / 20 / 40 nm (0.0511 / 0.0258 / 0.0133).
3. The inverted-population warning is emitted once per call (listing the count) instead of once per pair.
4. Q7.3 (plan, REJECT "local |psi|^2-weighted eps_zz(z)"): agreed -- this package builds the nonlocal response

## Release-note lines

- `IntersubbandEffect`: eps_zz is eps_inf + the intersubband sum (no Drude term of the sub-band electrons along z,
  which the f-sum rule already contains); `z_response="drude_plus_subbands"` restores the old form (deprecated,
  removal in 0.17). Dipoles use the eigenvectors' own quadrature (origin-invariant). New: `last_fsum_ratio` with an
  advisory, `free_density_m3`, `subband_mass_kg`, `thickness_m`, `subband_dipole_matrix`.
- New `optics.quantum_film`: self-consistent (RPA / adiabatic LDA) out-of-plane response of a confined degenerate
  film -- multisubband plasmon modes, nonlocal sigma_zz kernel, exact planar p-pol element composable with
  `nonlocal_tmm`, thin-film effective layer and sheet response lengths; `QuantumFilm.from_dual_gate`.
