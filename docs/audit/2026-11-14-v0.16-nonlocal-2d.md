## Public API

```python
from dynameta.optics.fem_2d_tm import TMLayer, TMBlock, solve_fem_2d_tm
from dynameta.optics.fem_2d_tm_hydro import hydro_conductor_from_profile, hydro_z_convergence
from dynameta.optics.nonlocal_tmm import hydro_layers_from_profile

prof = dict(m_eff_kg=0.30 * M_E, eps_inf=4.0, gamma=1.2e14, convention="high_freq", D=0.0)
run  = hydro_layers_from_profile(z_m, n_m3, **prof)          # planar route (z_m[0] = top face)
film = hydro_conductor_from_profile(z_m, n_m3, **prof)       # 2-D route, SAME arguments
layers = [TMLayer("mirror", 80e-9, -120 + 20j), ..., TMLayer("film", film.thickness_m, film), ...,
          TMLayer("grating", 40e-9, 1.0, (TMBlock(x0, x1, -60 + 4j, "strip"),))]   # bottom first
sol = solve_fem_2d_tm(400e-9, layers, lambda_m=1200e-9, n_sub=1.45, polarization="x",
                      return_solution=True)
sol.result.r, sol.result.per_region_absorption["film"], sol.energy_residual
sol.diagnostics["hydro"]["film"]   # {'validity': HydroValidity, 'u_max', 'h_z_nm', 'rows',
                                   #  'kL_max_per_nm', 'ndof_current', 'ndof_potential', 'absorption'}
rows = hydro_z_convergence(400e-9, layers, h_factors=(2, 1, 0.5), orders=(4, 5), lambda_m=1200e-9,
                           n_sub=1.45, polarization="x")
```

## Formulation, and why (measured)

Kernel reused, not re-derived (nonlocal_tmm, P9): (d/dt + gamma) J = eps0 wp^2 (E + grad psi), psi =
c rho1, c = `hydro_psi_per_charge` = -beta_eff^2/(eps0 wp^2), wp^2 proportional to n0, beta =
`beta_from_density(n0)`; (E_t, H_t, J.n, psi) continuous inside one conductor, J.n = 0 at its
boundary. The coefficients are evaluated by the kernel functions themselves (`eps_transverse`,
`hydro_psi_per_charge`) on CoefficientFunction-valued wp and beta, so no formula is duplicated.

Unknowns on the solver's product space: H_y in H1 (cell, Bloch-periodic), the free current X in
vector L2 (conductor), phi = i omega eps0 psi in H1 (conductor, Bloch-periodic). With J(a, b) =
(-b, a) and E = (J grad H - X)/(-i omega eps0 eps_inf) in the conductor:

    (M)  int Lambda grad H . grad v - k0^2 H v - int_C (1/eps_inf) X . J grad v            = src
    (K)  int_C (1/Delta + 1/eps_inf) X . K - (1/eps_inf) (J grad H) . K + grad phi . K
                                                             = int_C (1/eps_inf) (J grad H_bg) . K
    (W)  int_C -kappa^2 phi w + X . grad w = 0,      kappa^2 = -L0^2/(eps0 c)

Lambda = 1/eps_inf in the conductor, Delta = eps_T - eps_inf. Complex symmetric. Boundary and
interface conditions, none imposed: J.n = 0 on the conductor's top/bottom faces is the natural
condition of (W); psi continuity is conformity of phi; J.n continuity inside is natural; tangential
E (with the free-current part) continuity is natural in (M); lateral Bloch periodicity is the
periodic spaces. Eliminating X in a uniform conductor gives exactly k_L^2 = `kL_squared`.

Choice by measurement:

| alternative | outcome |
|---|---|
| (a) phi alone, X eliminated analytically (coefficients 1/eps_T, Delta eps_inf/eps_T) | implemented as a probe. Planar graded film whose Re eps_T crosses zero, vs nonlocal_tmm: equal to (K)-(W) once refined, but at the default mesh several times less accurate at low damping, equal at the fixture's damping; ~25 % fewer DOFs. Rejected because its coefficients are singular where eps_T = 0, which a graded accumulation / depletion film has by construction (lossless gamma = 0 still ran, but only because no quadrature point hits the zero). |
| (b) J in H(div), J.n = 0 essential | not built: the hard wall would have to be imposed on interior mesh edges (no boundary markers there), a Bloch-periodic H(div) space, ~2x the current DOFs of the element-local L2 X. Same physics as (K)-(W). |
| (c) hydro_fem's stabilised psi = div J | its continuous field is div J (proportional to beta^2 n1 for one mass), the wrong interface quantity for graded density; exact only for a uniform conductor. Used as an independent check on a uniform film (gate G), where it agrees. |
| (K)-(W) shipped | no eps_T in any denominator (like the planar generator); measured agreement 1.4e-10 with the planar route at order 4 (generic film). |

X order: L2 order p (contains grad of the order-p phi); order p-1 changes the strip r slightly and
saves few DOFs, not worth the inf-sup risk.

One implementation trap: an H1 space with a volume `definedon` still carries DOFs on the cell's
left/right BOUNDARY segments outside the conductor (boundary elements are not restricted); nothing
assembles there, so UMFPACK reported a singular matrix. The extension keeps free only the DOFs of
the conductor's own elements (`FreeDofs()` is a reference the product space reads).

## Mesh

Conductor rows of height h_z = `h_per_screening` / max|k_L| (default 1.0; or `h_z_m`), plus the
profile samples as lines (when <= `max_grid_lines`), plus optional geometric face grading. The
optical mesh outside the conductor is unchanged by these controls (gated). In the exact local
limit the conductor carries exactly the sample lines, so the mesh equals the local solve's.

An extension may set `condense = True`; `solve_tm_cell` then statically condenses the element-local
DOFs (the L2 current, and H1 bubbles) before UMFPACK. Only the hydrodynamic path uses it.

## Supported / refused

Supported: one or more conductor layers (each its own conductor, separated by non-hydrodynamic
layers) with n0(z) or n0(x, z) > 0, under or over strips/blocks in other layers; 'x' at normal
incidence and 'p' oblique (Bloch-periodic); 'high_freq' / 'thomas_fermi'; GNOR D; real eps_inf;
diffracting cells (energy is order-summed); opaque substrates.

Refused with a message: hydrodynamic BLOCKS (nonlocal strips) and claddings; blocks inside a
hydrodynamic layer; two adjacent hydrodynamic layers (ambiguous wall: give one profile);
`HydroParams` / `HydroLayer` / `HydroSlab` / finite-k Mermin as eps (the existing refusal, now naming
`HydroConductor2D`); complex eps_inf; n0 <= 0; a z span not matching the layer; `n_layers` in
`hydro_conductor_from_profile`. The Design / run_pipeline adapter does not accept hydrodynamic input
(unchanged refusal).

## Release-note line (for P15)

`fem_2d_tm` + new `fem_2d_tm_hydro`: a nonlocal (hydrodynamic) conductor layer with graded density
n0(z) or n0(x, z) inside the 2-D periodic TM cell (`HydroConductor2D`,
`hydro_conductor_from_profile` with the planar route's arguments, `hydro_z_convergence`, validity
report in `TMSolution.diagnostics`); agrees with `nonlocal_tmm` to 1e-10 on planar films and with an
independent E-field discretization on strip cells.

## Left undone / uncertain

- Hydrodynamic strips (nonlocal metal blocks with corners) are refused; the formulation would
  accept them (natural hard wall on any conductor boundary) but corner resolution of the
  sub-nanometre longitudinal layer was not studied.
- Runs of adjacent hydrodynamic layers are refused (give one profile per connected gas).
- A laterally varying density has no independent oracle (consistency checks only); beta^2 is
  bilinear on the voxel grid there (z on 2049 uniform points).
- The fixture film is outside the hydrodynamic model's validity (u = 1.06 > 0.5): the solver is
  correct for the model; the model itself needs a Lindhard-level response there (P9's caveat).
- Dense profiles (> max_grid_lines samples) are not aligned with mesh lines and converge at a
  reduced rate (~1-1.5 in h); raise `max_grid_lines` or resample the profile.
- Bitwise reproducibility of the hydrodynamic path was not a goal (threaded assembly); every gate
  uses a tolerance.
