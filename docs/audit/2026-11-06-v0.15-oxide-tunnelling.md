## 2. The physics, re-derived (the primary was not read)

**Source status.** Tsu & Esaki, Appl. Phys. Lett. 22, 562 (1973) could not be read (paywalled; a web search
found only bibliographic records). The current expression below is DERIVED here and agrees with the Silvaco
ATLAS manual's Eq. 3-144/3-145 (`scratchpad/lit_bgn/atlas.txt`, SECONDARY), whose prefactor
4 pi q m* kT / h^3 equals q m kT / (2 pi^2 hbar^3). A 1985 APL paper (47, 172) reportedly corrects the
original one-particle expression and adds a two-body term (abstract only, UNVERIFIED); the one-particle form
used here is the standard one.

### 2.1 Current

Electrons of normal energy E_x and transverse energy E_t, parabolic bands, conserved transverse momentum
(one transverse mass m for both sides), spin 2, transmission T(E_x):

    J = q Int (2 d^2k_t / (2 pi)^2) Int (dk_x / 2 pi) v_x T (f_s - f_g)
      = (q m / (2 pi^2 hbar^3)) Int dE_x T(E_x) Int_0^inf dE_t [f_s(E_x + E_t) - f_g(E_x + E_t)]

(d^2k_t = 2 pi m dE_t / hbar^2, v_x dk_x = dE_x / hbar). With f_a = 1/(1 + exp((E - E_Fa)/kT)) the transverse
integral is N_a(E_x) = kT ln(1 + exp((E_Fa - E_x)/kT)), so

    J = (q m kT / (2 pi^2 hbar^3)) Int_{E_c,s}^inf T(E_x) [ln(1 + e^{(E_Fs - E_x)/kT}) - ln(1 + e^{(E_Fg - E_x)/kT})] dE_x.

The integrand is zero POINTWISE when E_Fs = E_Fg (detailed balance by construction). The lower limit is the
semiconductor conduction edge at the interface (electrons only, decision 14). The gate band bottom must lie
below it (refused otherwise).

### 2.2 Transmission and barriers

T = exp(-theta), theta = 2 Int kappa dx, kappa = sqrt(2 m_j (U(x) - E))/hbar. In a charge-free layer U is
linear between its face values. With A = U_a - E, B = U_b - E:

    theta_j = c_j (A_+^{3/2} - B_+^{3/2}) / (A - B),   c_j = 4 sqrt(2 m_j) t_j / (3 hbar),

written cancellation-free as c (A + sqrt(AB) + B)/(sqrt A + sqrt B) when both are > 0. Barriers by Anderson
affinity: the layer's edge above E_c,s at a common potential is offset_j = chi_s - chi_j = the fitted barrier
when the semiconductor is the one it was fitted against (decision 13). Face potentials are read from the
solution: U_j at a face = q(psi_s - psi_face) + offset_j.

### 2.3 Shot noise

For T << 1 (Landauer-Buttiker, partition f_s(1 - f_g) + f_g(1 - f_s)):

    S = 2 q^2 (m / (2 pi^2 hbar^3)) Int dE_x T Int dE_t [f_s + f_g - 2 f_s f_g].

With r = e^{(E_Fs - E_Fg)/kT}, the partial fraction 1/((1 + a)(1 + r a)) = [1/(1 + a) - r/(1 + r a)]/(1 - r)
gives Int f_s f_g dE_t = (N_s - r N_g)/(1 - r), and the bracket integrates to (N_s - N_g) coth(Delta/2),
Delta = (E_Fs - E_Fg)/kT, which is independent of E_x. Hence

    S = 2 q J coth(qV / 2kT),   qV = E_Fs - E_Fg   (DERIVED; the classic tunnel-junction form),

which is 4kT dJ/dV at equilibrium and 2q|J| for |qV| >> kT. The one-sided sum 2q(J_fwd + J_bwd) drops the
Pauli term -2 f_s f_g; it is right only for a non-degenerate supply.

### 2.4 Supply, frame, gate

E_Fs - E_c,s = kT [ln u + Delta(u)], u = n_s/N_dos: the bulk's own closed-form FD log-activity
(`physics_heterojunction.setup_log_activity`, reused; Boltzmann: Delta = 0).

**The chi = None rule (decision 13 as accepted).** On the semiconductor the barrier was fitted against, the
barrier is used as given even when that semiconductor's chi_eV is None, because no affinity is derived. The
refusal happens only when an affinity must actually be derived: carrying the barrier to another
semiconductor needs both chi values. The `DielectricBarrier` docstring says so. E_c,s = q(phi_c - psi_s), with
phi_c = V_t ln(N_dos/n_i) (the bipolar frame) or the builder's Anderson frame. Gate: E_Fg = -q V_gate (bias
parameter or circuit node). Its barrier is read from the contact offset: phi_Bg = q(phi_c - offset) +
offset_last (decision 12); W_m = chi_s + phi_c - offset (`gate_offset_for_work_function`).

### 2.5 Equations

-A_i J_i on the `ElectronContinuityEquation` row of interface node i (A_i its SurfaceArea), +Sum A_i J_i on
the gate's KCL row when circuit-driven (the gate's circuit node is read live from the registry). The Jacobian
is the exact derivative of the discrete fixed-grid sum (psi_s, n_s via g/n, each face potential with its
lateral weights, the gate node). Static: nothing for "TIME".

**Image force (decision 15)**: not added. sqrt(qE/(4 pi eps_opt eps0)) with eps_opt = 2.13 is 0.26 V at
1 MV/cm (arithmetic, not a citation); the 3.1 eV Lenzlinger-Snow barrier is an FN fit that already absorbs
it. **Poly-Si gates (decision 17)**: refused. **Holes (decision 14)**: not modelled; the report warns where
p_s > n_s under |E_ox| > 1 MV/cm.

## 5. The gmsh mesh caveat (MEASURED, `sc_gmsh` scenario)

Stack: `Stacked3DSpec` Si n 1e24 / 2 nm SiO2, 4 nm cell, 1.2 V, laterally uniform. The term was read on the
solved ideal-capacitor state.

| Mesh | V_ox spread | per-node J spread | I/A vs tensor |
|---|---|---|---|
| tensor (Kuhn) | 0 | 0 | (290.87 A/m^2) |
| gmsh, DEVSIM geometry | 5.05 % | 92 % | -3.1 % |
| gmsh + `apply_exact_geometry(negative='warn')` | 0.59 % | 10.5 % | -4.9 % |

The exact geometry reduces the spread 8.6x but does NOT remove it. The residual is the unstructured FV
solution's own lateral noise, amplified |d ln J/d ln V_ox| ~ 15-18x at the nodes. Hence
`setup_oxide_tunneling` WARNS (`UnreliableResultWarning`) on any mesh that is not column-aligned, quoting
these numbers, and is silent on tensor meshes (gated). The plan's 1.5 % -> 37 % came from the 4 nm v0.14
stack. Not refused: a warned unstructured mesh is still usable qualitatively.

## Release-note lines

* New self-consistent gate-oxide tunnelling, `OxideTunnelingParams(model="tsu_esaki",
  coupling="self_consistent", barriers=SIO2_ON_SI, gate_fermi_energy_eV=...)` (also through the 2-D/3-D
  builders):
  * two-sided Tsu-Esaki/WKB through dielectric stacks;
  * zero current at equilibrium and supply-limited by the solved surface density;
  * conserves terminal current;
  * enters ssac and noise (tunnel shot noise, `tunnel_ox`).

  FN and Schuegraf-Hu remain post-processors only.
* DC terminal currents (`extract_contact_currents`, `contact_currents_A`) now include a gate's
  self-consistent tunnelling current. DEVSIM reports 0 for a dielectric gate in DC.
* Known limits: electrons only; no image force (the fitted barrier absorbs it); unstructured (gmsh) meshes
  warn, since they spread the current by ~10-90 % across the interface; no measured stack J-V validation
  yet.
