## Terms (plain language)

- **DG (density gradient):** drift-diffusion plus one extra "quantum potential" Lambda per carrier population.
  Lambda acts as a band-edge shift that grows where the density curves sharply; next to a hard wall it pushes
  the carriers off it (a "dark space" ~1 nm thick). Lambda = b lap(sqrt n)/sqrt n, b = gamma hbar^2/(6 m q).
- **gamma:** a dimensionless factor on hbar^2/(6 m). gamma = 1 is the first-order (Wigner) value;
  `GAMMA_WALL` = 1.6717 makes the dark space at a hard wall equal the exact free-gas one (a-priori).
- **Valley / valley set:** silicon's conduction band has six equivalent minima (valleys). With the gate oxide
  on a (100) face, the 2 valleys whose long axis is normal to the oxide quantize with the heavy longitudinal
  mass m_l = 0.916 m0; the other 4 with the light transverse mass m_t = 0.19 m0. Equivalent valleys form a set.
- **Quantization mass m_z:** the effective mass along the confinement direction. **Share:** a set's fraction of
  the effective density of states N_c in the classical limit (Si: number of valleys / 6).
- **SP (Schrodinger-Poisson):** the reference model. Here DynaMeta's own `sp_inversion` oracle with the same
  Si(100) valleys, made **DOS-consistent** (each valley degeneracy / 1.3716, so its classical limit has the
  drift-diffusion N_c: the 2026-11-08 correction).
- **N_inv / centroid:** the inversion sheet density (electrons per m^2 above the bulk value) and its mean depth.
- **Closure:** `setup_quasi_equilibrium_carrier`, the v0.15 algebraic row "the electron quasi-Fermi level is the
  body's" that replaces the continuity row of a MOS capacitor (exact there, and it converges in strong
  inversion). **Full transport:** the continuity row with its Scharfetter-Gummel (SG) current.

## 1. The model (what was built)

Each valley set k (a `ValleySet` row: m_z, share s_k; N_k = s_k N_c) gets its own pair u_k = sqrt(n_k) and
Lambda_k, through the SAME kernel as the isotropic DG (`_install_dg_variables`, now with an optional `tie`):

    Lambda-row   b_k lap(u_k) - Lambda_k u_k = 0,                 b_k = gamma hbar^2/(6 m_z,k q)
    u-row k = 0  sum_j u_j^2 - n = 0                              (Poisson, SRH, continuity see the total n)
    u-row k >= 1 V_t [A(n_k/N_k) - A(n_0/N_0)] - (Lambda_k - Lambda_0) = 0

A(x) = ln x + Delta(x) is the region's activity (Boltzmann: ln x; `statistics='fermi_dirac'`: the existing
closed-form FD correction `setup_log_activity`, reused). The second row says all sets share ONE electron
quasi-Fermi level (intervalley equilibrium): n_k = N_k F(eta + (psi + Lambda_k)/V_t) with one eta. With all
Lambda_k = 0 it gives n_k = s_k n exactly (FD too), so the classical limit is the region's N_c.

**The current (phase B, derived).** One mobility and one quasi-Fermi level phi_n give J = q mu n grad(phi_n)
for the TOTAL density, and the total obeys n = sum_k N_k F(eta + (psi + Lambda_k)/V_t) =: N_c F(eta + (psi +
Lambda_eff)/V_t), which defines Lambda_eff uniquely (F is monotone). So the total is a single population in
the band edge psi + Lambda_eff, and the existing single-population DG SG flux applies unchanged with Lambda ->
Lambda_eff (same kernel and Bernoulli argument, the FD quasi-field and BGN included). At a node, from the
k >= 1 rows: Lambda_eff = Lambda_0 + V_t [A(U/N_c) - A(n_0/N_0)], U = sum_k u_k^2 (Boltzmann: V_t ln sum_k s_k
exp(Lambda_k/V_t), the research note's 7.2 form). `QLambda` is this node MODEL in valley mode, with its exact
derivatives w.r.t. every u_k and Lambda_0 as models that DEVSIM's diff() looks up by name (checked: DEVSIM
differentiates a model reference M to the model "M:var", and an edge reference M@n0 to "M@n0:var@n0"; a missing
one is silently 0 -- so every chain model is created, and the whole Jacobian is gated against finite
differences). The quantum SRH re-reference uses Lambda_eff (DG equilibrium n p = n_i^2 exp((Lambda_eff +
Lambda_p)/V_t)). Why not one SG flux per set, summed: that holds each set's current constant along an edge,
i.e. no intervalley transfer inside an edge, which contradicts the shared quasi-Fermi level.

**A formulation finding (measured).** Lambda_eff first written with A(n/N_c) of the Electrons VARIABLE put
ln(n) of the flux's own density into its Bernoulli argument (the quasi-Fermi form of SG). On the GATE F p-n
diode the Newton then DIVERGED on the 0.40 -> 0.35 V step back (relative update 2e3 at iteration 0, residual
1e116 at iteration 3). Written on U = sum u_k^2 (equal to n at convergence, so the same discrete solution) it
converges exactly like the isotropic DG: 6-7 iterations per forward 50 mV step, 11 per backward step, for the
isotropic DG, two identical sets and the Si(100) sets alike.

**The closure** (phase A) is written on the reference set: R_n = phi_ref - [psi + D_c + Lambda_0 - V_t (A(n_0/N_0)
+ ln(N_c/n_i))] -- the single-population row with Lambda -> Lambda_eff, in which A(n/N_c) cancels exactly. Its
written-out Jacobian moves from Electrons to u_0 (`physics_bipolar_dd`, a hook that returns None otherwise).

**Walls, contacts, seed, gamma ramp.** Insulator wall: u_k = u_floor_rel sqrt(s_k n_cl) per set, and the set's
u-row moves to its Lambda row (the single-population wall, per set). Ohmic contact: Lambda_k = 0 and the bulk
u-rows. Seed: the classical split, and next to a wall each set's own tanh(d/L_q,k) shape. `set_dg_gamma`
co-ramps every set. All from one copy of the rows (`_valley_tie`).

## 2. API

- Data: `density_gradient.ValleySet(name, m_z_kg, dos_share, m_xy_kg=None, degeneracy=None)`; the preset
  `SI100_ELECTRON_VALLEYS` (2-fold m_l share 1/3, 4-fold m_t share 2/3); `check_valley_table`. Other
  orientations are other tables (data, not code).
- Item 1: `setup_bipolar_dg(dev, region, electron_valleys=SI100_ELECTRON_VALLEYS, m_eff_p_kg=..., gamma_n=GAMMA_WALL,
  gamma_p=...)` (instead of `m_eff_n_kg`). Then `setup_contact_bipolar_dg`, `setup_dg_insulator_wall`,
  `seed_bipolar_dg`, `set_dg_gamma` and `setup_quasi_equilibrium_carrier` work as before. Read back:
  `electron_valley_sets`, `valley_densities`; `QLambda` = Lambda_eff.
- Item 2: `gamma_n=GAMMA_SI100_SP_CALIBRATED` (= 1.88) with the Si(100) sets.
- Refused: `m_eff_n_kg` and `electron_valleys` together; `statistics='legacy'`. A one-set table installs the
  isotropic rows (bit-identical solve, gated).
- Harness: `mos_qe(..., valleys=...)` (records `n_v`), `diode(..., valleys=..., probe=...)`, `sp_valleys(table)`
  (DOS-consistent SP valleys from the same table), `valley_shares(rec)`.

## 4. Phase B: full transport (measured)

- (i) One set: bit-identical by construction (section 3). Two identical sets: the diode's currents and densities
  are bit-identical to the isotropic DG's (the extended Newton converges both to the correctly rounded double).
- (ii) Equilibrium: the full model's electron quasi-Fermi level (written on the reference set as the closure
  does) is flat to 2.8e-16 V; in the diode at 0 V every edge current is 2e-29 of q mu n_max V_t / h.
- (iii) Full model == closure where both converge (the full DG installed at the target bias, extended Newton
  REL 1e-10; Boltzmann and FD at 0.1 / 0.35 / 0.6 V, measured on the final flux form): <= 1.1e-15 in n, p, every set's density and Lambda_eff.
  Named perturbation, the flux on Lambda_0 instead of Lambda_eff: 49-57 % apart and the quasi-Fermi level 24-35 mV
  non-flat (gated).
- (iv) The GATE F p-n diode (1e23 / 1e22, no wall, Boltzmann) with the Si(100) sets: terminal currents conserve to
  2.1e-16; the DG change of the current is first order and linear in gamma (change(1)/change(1/2) = 1.996 at
  +0.4 V, 2.005 at -0.5 V); it is -8.25e-5 (forward) / +6.80e-3 (reverse) against the isotropic DG's -8.28e-5 /
  +6.77e-3 -- in a smooth potential (max Lambda 0.02 V_t) the set masses matter only at second order.
- Not done: ssac / noise on the FULL valley model. ssac on the closure is gated; the full model's small-signal
  matrix is the DC Jacobian (gated exact) plus the unchanged time terms, so it is expected to work, but it was
  not measured. noise_analysis was not checked with valley sets (its edge-conductance model reads the flux's
  Bernoulli argument, which is unchanged in form).

## 5. Phase C: the calibrated gamma (measured on this implementation)

`density_gradient.GAMMA_SI100_SP_CALIBRATED = 1.88`, opt-in. Its comment states: a FIT to DynaMeta's anisotropic
SP oracle (effective mass, parabolic, infinite barrier, classical holes, 300 K, fixed surface potential), for
the valley-resolved Si(100) DG with FD statistics and the closure, N_A 1e23-1e24 m^-3, 1.00-1.30 V (21 points,
N_inv 1.4e14-1.3e17 m^-2), and the literature basis for calibrating at all (Biegel et al.; Watling et al.;
Schenk; Pons et al.; quotes in the comment).

- Choice: the two-decimal value minimizing the largest |N_inv error| over the 21 points, by direct runs at 1.86
  / 1.87 / 1.88: max 2.10 / 1.51 / 1.33 %. (A spline over the gamma grid put the continuous minimax at 1.875.)
- Residuals at 1.88: **N_inv -1.33 .. +0.93 %** (all 21; -1.33 .. +0.28 % for N_inv >= 1e16), **centroid -2.75 ..
  +1.51 %**. GATE VC re-measures them.
- gamma*(N_inv) per point: 1.82 .. 1.90. The prototype found 1.87-1.93 "with no drift". Here it drifts down by up to
  0.08 toward the highest band bending (1e24: 1.893 at 1.0 V, 1.816 at 1.3 V); at 1e23 / 3e23 by <= 0.04. The
  lower level is consistent with the FD offset above (this DD's N_inv is lower at equal gamma).
- GAMMA_WALL stays the default wall value; the default gamma stays 1.

## 6. The default decision: measurements

The user leans toward making the valley-resolved model the default for Si electrons. What that needs:

**Accuracy** (section 3, same 21-point matrix, against the DOS-consistent anisotropic SP, GAMMA_WALL): N_inv
error +2.9 .. +7.9 % (N_inv >= 1e16; up to +14.5 % near threshold) against the isotropic model's -8.7 .. -39 %;
centroid -1.2 .. -5.2 % against +8.8 .. +24 %. The valley-resolved error is smaller at every point (gated, VA-3).
With the calibrated gamma: within 1.33 % / 2.75 %.

here ("most likely the direct solver's pivoting / fill on the isotropic system") pointed at the right component
but the wrong cause, and the table above is NOT a property of either model. Measured: DEVSIM's bundled UMFPACK 5.1
picks its obsolete "2-by-2" strategy (disabled upstream in UMFPACK 5.4.0, 2009) for EVERY DG + closure
Jacobian, isotropic AND valley-resolved alike, and its numeric factorization fills in by 1.0-43x over the
symmetric strategy on the same ordering; 89-97 % of the slow isotropic iterations was that factorization. How
badly it filled was the luck of the pivot sequence (isotropic 17-43x, valley 1.0-4.2x), which produced the
apparent "valley model is faster". With `devsim_env.umfpack_2by2_guard` (2-by-2 redone as symmetric) the same
probe gives, Windows, ms per iteration isotropic / valley-resolved: 1-D 10.4 / 17.9, 1-D hole DG 12.9 / 19.1,
2-D 28.0 / 48.8, 2-D hole DG 33.4 / 46.3; whole ramps 2.16 / 3.86, 2.83 / 4.78, 3.02 / 4.95, 3.94 / 6.31 s. The
valley-resolved model now costs what its size says on all four fixtures: 1.4-1.7x per iteration, 1.6-1.8x per
ramp (equal or fewer Newton iterations), and the isotropic DG itself got 6.6-26x cheaper per ramp in the three
fixtures that were slow (1-D electron-only: unchanged, 2.11 -> 2.16 s).

**Robustness** (measured):
- G1-3 matrix with the sets (GATE VG; hole DG + sets, both closed, every 50 mV step to 1.3 V, N_A 3e23 / 1e24,
  gamma 0.5 / 1 / GAMMA_WALL, double): every step <= 10 Newton iterations in all 6 configurations, valley-resolved
  and isotropic alike (GATE VG, PASS).
- The diode ramp 0 -> 0.4 -> 0 V: identical iteration pattern to the isotropic DG (6-7 / 11).
- The full DG model's own psi ramp in a MOS (no closure, DG installed at flat band) fails for BOTH models
  (Boltzmann and FD, at the 0.05 -> 0.10 V step in this fixture: default mesh, tau 1e-7 s, double), as documented for the isotropic DG in v0.15 (use the closure or dg_at_target).
- No ramp found that converges for one model and not the other.

**Other materials and holes.** The table is Si(100)-specific. `setup_bipolar_dg` takes masses, not materials or
orientations, and DynaMeta has no crystal-orientation input anywhere; the DG is not reachable from
`LayeredDevsimBuilder`. A default at the function level would therefore have to guess "this region is Si(100)"
(wrong for (110)/(111) Si, strained Si, SiGe, III-V, ITO: other tables or the isotropic model). Holes are a
single population in both models (Pons: the DG fails on hole densities anyway).

**What a default would move.** Every gate whose oracle is the isotropic single population: GATE G (G1-3, G1-4
and its pin `G14_NINV_PIN`, G1-5, G1-7), D2d GATE C (electron accumulation vs the isotropic SP), GATE D (the
post-hoc BVP is single-population), GATE F's diode numbers; in tests: test_quasi_equilibrium's DG cases (G1-2b,
G1-3, the 2-D DG case), test_bipolar_density_gradient's DG physics gates, and the new defaults-off digest
(`tests/_bipolar_dg_calllog.py`). Each would need the isotropic option passed explicitly or a valley-aware
oracle. The unipolar DG (`setup_dg_quantum_correction`, ITO) and its digest would not move.

**Recommendation: keep it opt-in at the function level now; make it the default where the material and
orientation are known.** Reasons: (1) the accuracy gain is large and systematic (error 2-5x smaller, the right
sign of the centroid, the repopulation captured), so for Si(100) electron inversion it should be what users
reach for -- the docstrings say so; (2) but `setup_bipolar_dg` cannot know that a region is Si(100), so a
function-level default would silently apply Si(100) physics to other materials and orientations; (3) the cost
(+29-40 % unknowns) is acceptable; robustness is equal. The natural place for the default is a builder-level DG
switch that knows the material and a crystal orientation (DG is not in the builders today; the v0.15 note
recommends wiring the closure there when the layered gated-bipolar offset is fixed). Flipping it there would
move the gates listed above only for Si(100) regions.

## 9. Limits (not measured)

Si(100) electrons only. Not covered: other orientations ((110), (111)) and strained Si (other tables, not
measured), holes (single population), valley-dependent mobility (one mu_n for all sets: the conductivity-mass
anisotropy is not modelled), intervalley non-equilibrium, oxide penetration (infinite barrier on both sides),
temperatures other than 300 K, 2-D/3-D confinement (the 2-D gate is laterally uniform), accumulation layers,
the unipolar DG (`setup_dg_quantum_correction` has no valley option), ssac/noise of the full valley model.
