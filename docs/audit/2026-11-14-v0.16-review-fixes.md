## 2. Finding 2 (a barrier-confined film between two oxide stacks per face, p 60 deg)

The response element of `from_dual_gate` reaches into each oxide; with the whole element over the designed
oxides the film's response was counted twice. Shortening the oxides is not the answer either: the element
carries the film's eps_inf where the oxide is, and that background error is first order in the depth. The
fold (this fix) removes it: its r converges with the element depth into each oxide (tail cut below ~1 nm
warns; the 2 nm default agrees with the whole-domain fold to ~1e-9), while the shortened-oxide r moves by
more than the bias modulation. Oracle of the fold: an element extended 2 nm into a +1e8 eV "oxide" (the
nominal film's electrons exactly) gives the nominal film's r to ~1e-10, where the staging code missed it by
several 1e-3. On staging the pipeline coupling refused a barrier film ("the state does not belong to this
carrier region"); it now runs, with the equivalent layer on the design layer. (The measured table of this
section was made on the earlier device-like fixture and was not re-measured on the generic fixture; the
quantum-film tests carry the gates.)
